# MicaBar

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · **Русский** · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

Сетевой монитор для Windows в стиле «динамического острова». Капсула из матового стекла вверху экрана показывает
выходной IP и число соединений; задержите на ней мышь — и увидите, какая программа какой порт использует, куда идёт
каждое соединение и через какой узел прокси, а также сразу решите, пустить его через прокси или напрямую.

## Возможности

- **Выходы по группам**: выходной IP и узел каждой группы подписки (прокси по умолчанию, AI, стриминг…) плюс прямой
  выход — со страной, провайдером / ASN, типом IP (домашний / бизнес / хостинг / мобильный, с отдельной пометкой, если
  IP числится как прокси) и владельцем (оператор и провинция для IP материкового Китая).
- **Сменяющаяся капсула**: выходы групп, играющая песня (обложка + название), лимиты AI, скорость и задержка узла
  показываются по очереди; что показывать и как часто — настраивается.
- **Лимиты AI**: использование подписок (окна 5 часов / неделя…) и время сброса для Claude Code, Codex, Antigravity
  и Grok, в центре каждого кольца — значок инструмента.
- **Работающие задачи AI**: пока Claude Code работает, в начале капсулы видны проект и прошедшее время; при ожидании
  вашего одобрения — оранжевым. То же вверху открытого острова; один щелчок выводит его терминал на передний план.
  Прерывание по Esc или закрытие терминала убирает его.
- **Диагностика сети**: лёгкая проверка каждые 10 с; два сбоя подряд запускают полную проверку по цепочке (адаптер →
  роутер → DNS → интернет → прокси-клиент → узел). Капсула говорит, какое звено упало («DNS сломан», «Узел упал»,
  «Нет интернета от провайдера»…), а в панели есть исправления: очистить кэш DNS, переключиться на рабочий узел,
  перезапустить прокси-клиент… После восстановления видно, сколько длился обрыв. Если другая программа выключила или
  изменила системный прокси, об этом сообщается с восстановлением в один щелчок.
- **Первый выход в сеть**: карточка на острове, когда программа впервые выходит в интернет — «Разрешить» или
  «Заблокировать» (правило брандмауэра Windows; при включённом управлении выходом блокируется и её трафик через
  системный прокси). При первом запуске 10 минут запоминаются привычные программы; папки версий объединяются, так что
  обновления не считаются новыми программами.
- **Уведомления**: новые сообщения WeChat, Telegram, почты и других программ, а также завершение задач и ожидание
  одобрения в Claude Code / Codex показываются на острове — значок программы в конце капсулы, строка внутри капсулы
  или карточка, на выбор; страница уведомлений группирует их по программам. Текст сообщений по умолчанию скрыт
  (только программа и отправитель); есть «Не беспокоить», тихие часы, заглушение по программам и перехват
  собственных окон программ.
- **Соединения по программам**: значок, число процессов, скорость отдачи / загрузки в реальном времени, программы
  через прокси первыми; для каждого соединения — локальный порт → домен / IP, страна, провайдер, узел и сработавшее
  правило.
- **Управление выходом** (Clash Party / Mihomo Party): для программы, домена, основного домена или «только эта
  программа к этому домену» — прокси / напрямую / блок, применяется мгновенно без перезапуска ядра; узел для
  «Прокси» можно сменить и протестировать прямо на острове.
- **Оповещения об утечках**: если сайт, который должен идти через прокси, пошёл напрямую, капсула краснеет и
  появляется уведомление Windows. Профилактика: промахи правил принудительно направляются в прокси; программам в
  обход прокси прямой выход блокируется в один щелчок (брандмауэр Windows).
- **Скорость / трафик / узлы**: график скорости в реальном времени, трафик «прокси / напрямую» по программам (сегодня,
  7 или 30 дней), задержка и потери узлов.
- **Системный монитор**: CPU / GPU / память по программам, завершение процессов; автозагрузка включается и
  выключается как в диспетчере задач.
- **Окно на рабочем столе**: обычно есть только остров и значок в трее; в окне — обзор (выходы, скорость, трафик,
  задержка, утечки, лимиты AI, самые активные программы) и все настройки.
- **Внешний вид**: живое матовое стекло (светлое / тёмное, как в системе), на котором текст читается на любом фоне,
  наборы цветов и свои темы; формы «капсула», «вырез» и «полоска» на любом краю экрана; разворот наведением или
  щелчком, режим «сквозь», своя горячая клавиша, управление с клавиатуры; не мешает полноэкранным играм; плавная
  анимация следует настройке анимации Windows.
- **10 языков интерфейса**: 简体中文, 繁體中文, English, 日本語, 한국어, Русский, Español, Português (Brasil),
  Français, Deutsch — по умолчанию язык интерфейса Windows.
- **История буфера обмена**: скопированный текст и картинки хранятся на странице «Буфер обмена» острова, нажатие копирует запись обратно. Поиск, закрепление, автоочистка по возрасту и количеству; содержимое, помеченное менеджером паролей как личное, не записывается.

> Внешний вид и взаимодействие вдохновлены [fly-island](https://github.com/flyl1u/fly-island), часть идей —
> [BrimDeck](https://github.com/MoFeng2223/BrimDeck); весь код написан самостоятельно.

## Установка

Скачайте с [Releases](https://github.com/aileboeth/MicaBar/releases):

- `MicaBar_<версия>_x64-setup.exe` — установщик (`C:\Program Files\MicaBar`), с обновлением из приложения;
- `MicaBar_<версия>_portable.exe` — один портативный exe, без автообновления.

Нужны Windows 10 2004+ / Windows 11 (x64) и среда WebView2 (встроена в Windows 11; установщик добавит её при
отсутствии). MicaBar работает с правами администратора (для скорости по программам нужны события ETW ядра), поэтому
при запуске спрашивает UAC; с включённым «Запуск вместе с Windows» он стартует из планировщика без запроса.

## Как пользоваться

При первом запуске тур на полминуты прямо на острове показывает основы, описанные ниже; повторить его можно в
Настройки → О программе → «Повторить тур».

### Развернуть и свернуть

| Действие | Результат |
| --- | --- |
| Задержать мышь на капсуле около 0,5 с | Разворачивается в панель (режим «Наведением» по умолчанию; задержка — в Настройки → Общие → Управление) |
| Увести мышь с панели | Сворачивается |
| Щелчок по капсуле / щелчок мимо | Развернуть / свернуть в режиме «Щелчком» (переключается в Настройки → Общие → Управление → «Как разворачивать») |
| `Ctrl+Alt+N` | Развернуть / свернуть в любой момент (чтобы сменить, щёлкните поле горячей клавиши в настройках и нажмите новое сочетание) |
| `Esc` | Свернуть панель; сначала закрывает открытую нижнюю панель или меню |

- В режиме «Наведением» свёрнутая капсула никогда не мешает щелчкам: пока на ней мышь, она становится прозрачной,
  видна закрытая ею вкладка, а щелчок уходит в окно под ней.
- **Режим «сквозь»**: мышь вообще не задевает остров, открыть его можно только горячей клавишей — удобно, если не
  хочется задеть его случайно.
- Когда впереди полноэкранная программа (игра, видео), капсула видна, но не разворачивается сама и не мешает
  щелчкам; можно также скрывать её полностью.
- Дополнительно «Сворачивать в полоску, когда окно развёрнуто»: пока впереди развёрнутое окно, капсула становится
  тонкой линией и возвращается, когда вы переключаетесь на другое окно.

### Перетаскивание, бросок и пристыковка

Остров пристыковывается к верхнему, нижнему, левому или правому краю экрана — в начале, середине или конце края.

1. **Схватить**: при развёрнутой панели **нажмите и держите неподвижно около 0,26 с** в любом месте панели (время —
   в Настройки → Общие → Управление → «Долгое нажатие, чтобы схватить остров»). В свёрнутом виде **зажмите `Alt` и
   долго нажмите на капсулу** (с зажатым Alt капсула не становится прозрачной, и нажатие хватает её, а не окно под ней).
2. **Бросить вдоль края**: схватив, резко потяните влево или вправо и отпустите — остров скользнёт к началу, середине
   или концу этого края.
3. **Перенести на другой край**: схватив, потяните к центру экрана — остров последует за мышью; отпустите у другого
   края, и он пристыкуется там. У левого / правого края капсула становится вертикальным вырезом.

Если перетаскивать не хочется, выберите край и положение на нём в Настройки → Вид в свёрнутом состоянии.

### Размер

- Правый щелчок по значку в трее → «Изменить размер острова…», кнопка «Изменить размер острова» внизу слева в окне
  на рабочем столе или Настройки → Вид в свёрнутом / развёрнутом состоянии → «Перетащите на экране, чтобы изменить»:
  у капсулы и панели на экране появляются перетаскиваемые края; тяните их, чтобы менять ширину и высоту, затем
  нажмите «Готово» (`Esc` — отмена).
- Или ползунки в Настройки → Вид в свёрнутом / развёрнутом состоянии: высота капсулы, ширина (0 = по содержимому),
  ширина панели, максимальная высота и масштаб интерфейса.

### Клавиатура

При развёрнутой панели: `Tab` / `Shift+Tab` переводят фокус по порядку; когда фокус на значках страниц вверху или на
вкладках страницы «Сеть», `←` / `→` переключают их; `↑` / `↓` двигаются по строкам и кнопкам списка; `Enter` /
`Пробел` разворачивают текущую программу; `Esc` сворачивает. Списки, которые можно упорядочивать в настройках,
понимают и `Alt+↑` / `Alt+↓` на выбранном пункте.

### Страницы

Значки вверху панели переключают страницы (Сеть, Система, Музыка, Лимиты AI, Уведомления); какие страницы видны и в
каком порядке — в Настройки → Вид в развёрнутом состоянии, а остров помнит, на какой странице вы были.

**Сеть**

- Наверху — **карточки выходов**. Слева выходы через прокси: по строке на каждый выходной IP с меткой типа (Домашний /
  Бизнес / Хостинг / Мобильный / Помечен прокси), на второй строке узел и владелец, а справа от IP — группы, которые
  его используют; что не помещается, сворачивается в «+N» — щёлкните, чтобы увидеть все, и «Свернуть», чтобы убрать.
  Справа — прямой выход (оператор, адаптер, обратный DNS, время последней проверки). Наведите мышь на IP или метку,
  чтобы увидеть владельца, провайдера, ASN и источник данных. ↻ справа вверху снова проверяет выходы; значок пульса
  рядом открывает **диагностику сети**.
- Строка под карточками показывает прокси-клиент, системный прокси, TUN, локальный порт и контроллер.
- Вкладки: **Соед. / Порты / Выход / Утечки / Скорость / Трафик / Узлы** (если не помещаются, прокручивайте колесом
  мыши; порядок меняется в настройках). Поле поиска справа фильтрует по программе, домену, IP или порту.
  - **Соединения**: по строке на каждую программу в сети (через прокси — первыми). Щелчок по строке разворачивает её
    соединения; кнопка «Выход» справа выбирает Прокси / Напрямую / Блок для всей программы, а «⋯» рядом с
    соединением — только для него (этот домен, этот IP или «только эта программа к нему»). Повторный щелчок по
    выбранной кнопке = вернуть правила.
  - **Порты**: прослушиваемые порты этого ПК; слушающие на всех адаптерах (доступные из локальной сети) помечены.
  - **Выход**: включение / выключение управления выходом, просмотр и удаление правил, смена и тест узла для «Прокси».
  - **Утечки**: утечки прокси и первые выходы в сеть; запрет прямого выхода, игнорирование домена, повторное разрешение.
  - **Скорость**: график скорости в реальном времени. Водите мышью влево / вправо — он прилипает к каждой секунде, а
    большие цифры следуют за ним; щёлкните программу под графиком, и снизу выедет панель с её графиком и числами.
    Панель тянется вверх / вниз, бросок вниз закрывает её; в ней есть «Показать её соединения» и «Показать только её
    на большом графике».
  - **Трафик**: трафик «прокси / напрямую» по программам за сегодня / 7 дней / 30 дней; щёлкните столбец, чтобы
    увидеть день.
  - **Узлы**: задержка и потери каждого выходного узла; «Тест сейчас» сразу запускает проверку.
- **Диагностика сети** (значок пульса или красное оповещение на капсуле, когда нет сети): проверяет всё от адаптера
  до узла, говорит, какое звено упало, и предлагает кнопки исправления (очистить кэш DNS, восстановить системный
  прокси, открыть / перезапустить прокси-клиент, переключиться на рабочий узел…).

**Система**: загрузка каждого ядра CPU / GPU, память и видеопамять; ниже переключение между «Самые активные
программы» (по CPU или памяти; ✕ завершает процесс после подтверждения — основные процессы Windows и сам MicaBar не
завершаются) и «Автозагрузка» (тот же переключатель, что «Автозагрузка» в диспетчере задач; выключение ничего не
удаляет).

**Музыка**: играющая песня (NetEase Cloud Music, QQ Music, Spotify, видео в браузере…) с обложкой, названием,
полосками в такт и кнопками назад / воспроизведение-пауза / вперёд.

**Лимиты AI**: по карточке на инструмент — сколько использовано в каждом окне и когда сброс; «Обновить сейчас»
проверяет сразу (официальные API строго ограничивают частоту; Claude не чаще раза в 10 минут).

**Уведомления**: сгруппированы по программам; щелчок открывает программу, есть «Прочитать все» и «Очистить все»;
**правый щелчок** по группе позволяет заглушить программу или очистить группу.

### Что показывает капсула

- Содержимое капсулы (выходной IP, скорость, кольца лимитов AI, часы, CPU / память…) отмечается и упорядочивается в
  Настройки → Вид в свёрнутом состоянии → «Содержимое»; что не помещается, объединяется в последней ячейке и
  показывается по очереди.
- Когда нет сети, изменён системный прокси или Claude Code работает либо ждёт одобрения, в начале капсулы появляется
  соответствующее оповещение; щёлкните его, чтобы открыть диагностику или перейти к терминалу.
- Смена выходного IP, узел не отвечает или стал медленным, всплеск трафика — кратко на 5 секунд
  (переключатели и пороги в Настройки → Сеть → «Короткие оповещения»).
- При утечках капсула краснеет; непрочитанные уведомления показывают значок программы и красную точку справа.

### Окно на рабочем столе, настройки и трей

- **Левый щелчок по значку в трее** или **шестерёнка** справа вверху панели открывают окно: Обзор, Соединения,
  Прослушиваемые порты, Управление выходом, Утечки, Скорость, Трафик, Узлы, Система, Лимиты AI, Уведомления и Настройки.
- **Правый щелчок по значку в трее**: Открыть MicaBar, Настройки, Изменить размер острова, Проверить выходной IP
  снова, Вид (как в системе / светлое стекло / тёмное стекло), Открыть журнал, Выход.
- Настройки сгруппированы в боковой панели (Основное: Общие, Вид в свёрнутом состоянии, Вид в развёрнутом состоянии,
  Тема панели; Выходы и оповещения; Лимиты и кольца; Сейчас играет; Уведомления; О программе), и любую функцию можно
  выключить; формы и темы выбираются по карточкам-превью, а списки с ⠿ упорядочиваются перетаскиванием. «Сбросить все
  настройки» — внизу.
- **Язык интерфейса**: Настройки → Общие → «Язык»; «Как в системе» по умолчанию берёт язык интерфейса Windows. После
  смены все окна перезагружаются, меню в трее тоже меняется.

## Выходы по группам

С включённым управлением выходом переопределение открывает для каждой группы прокси порт, слушающий только этот ПК
(с `127.0.0.1:47800`), трафик из которого идёт прямо в эту группу. MicaBar проверяет выходной IP через каждый порт и
знает, откуда выходят «по умолчанию», «AI» или «YouTube». По умолчанию показываются резервная группа и группы с
недавним трафиком (до 4); группы можно выбрать и вручную.

## Управление выходом

Когда обнаружен Clash Party / Mihomo Party, остров предлагает включить управление выходом. Включение сохраняет
список переопределений Clash Party, добавляет глобальное переопределение «MicaBar 出口控制» и один раз
перезапускает Clash Party (около 3 с без сети); если ядро не сможет его загрузить, всё вернётся как было. Дальше
выбирайте цель через «Выход» в строке программы или «⋯» у соединения. Более конкретные правила важнее, так что
«эта программа напрямую» и «только эта программа к *.example.com через прокси» работают вместе. Переопределение
удаляется внизу вкладки «Выход».

В режиме системного прокси управлять можно только программами, которые его соблюдают; чтобы охватить все, включите TUN.

## Поддерживаемые прокси-клиенты

| Клиент | Выход через прокси / локальный порт | Узлы, группы, сработавшие правила | Управление выходом / профилактика утечек |
|---|---|---|---|
| Clash Party / Mihomo Party | ✓ | ✓ | ✓ |
| Clash Verge Rev | ✓ | ✓ (через его контроллер) | — |
| v2rayN, Throne (NekoRay), Hiddify, FlClash, Karing | ✓ (порт системного прокси или их обычный локальный порт) | — | — |

Системный прокси, адаптер TUN и соединения по программам показываются при любом клиенте.

## Уведомления

Уведомления берутся из трёх мест, всё читается локально:

- **Мигание панели задач**: WeChat 4.x сообщает о новом сообщении только миганием кнопки на панели задач (без
  уведомления Windows и без читаемого окна), поэтому остров может сказать лишь «WeChat · N новых сообщений»; щелчок
  открывает WeChat. Так же работают другие мигающие программы.
- **Собственные окна программ / уведомления Windows**: с выключенными уведомлениями Windows Telegram показывает свои
  окошки в углу; когда такое появляется, MicaBar один раз читает список чатов Telegram (Windows UI Automation) и
  находит чаты, где выросло число новых сообщений. Программы с уведомлениями Windows читаются из системной базы
  уведомлений. «Перехватывать окна» скрывает собственное окно программы (или Windows), и показывает только остров.
- Программы с уведомлениями Windows (WhatsApp, Teams, Slack, Discord, Signal, Zoom, LINE…) отображаются со своим
  именем и значком; сообщение, которое и мигает на панели задач, и выдаёт уведомление, считается один раз.
- Открытие программы помечает её уведомления прочитанными и убирает красную точку; о пришедшем, пока вы в этой
  программе, не сообщается.
- **Оповещения AI о завершении**: «Подключить» в Настройки → Уведомления добавляет хук в `~/.claude/settings.json`
  Claude Code или `~/.codex/config.toml` Codex (сначала резервная копия, удаляется в один щелчок); при завершении
  задачи или ожидании одобрения он сообщает на `127.0.0.1:47900` через `curl` (со случайным токеном).

## История буфера обмена

- Скопированный текст и картинки (скриншоты и т. п.) идут по времени на странице «Буфер обмена» панели, закреплённые — сверху; повторное копирование того же содержимого только поднимает его наверх.
- Нажатие на запись лишь снова кладёт её в буфер обмена — вставляете вы сами через Ctrl+V. Наведите на запись, чтобы закрепить или удалить её; поиск — вверху.
- Настройки → Буфер обмена: записывать ли картинки, хранить историю на диске этого ПК (зашифровано ключом текущей учётной записи Windows, сохраняется после перезапуска) или только в памяти, сколько дней и записей хранить. Закреплённые записи никогда не удаляются автоматически.
- Менеджеры паролей (Bitwarden, KeePass, 1Password и др.) помечают скопированные пароли как «не записывать»; такое содержимое по умолчанию пропускается.
- Значок буфера обмена справа в капсуле подпрыгивает при новом копировании (выключается в Настройки → Вид в свёрнутом состоянии).

## Оповещения об утечках

Библиотека «должно идти через прокси» = встроенный список популярных сервисов (~140 основных доменов) + список gfw
(обновляется ежедневно) + свои записи / импортированные списки (просто домены, форматы v2fly и Clash). Два вида утечек:

- **Промах правил**: соединение прошло через прокси-клиент, но правило отправило его напрямую. С включённым «Ловить
  заранее» такие домены отправляются в прокси раньше, чем дойдут до прямых правил подписки; группы подписки по
  сервисам не затрагиваются.
- **В обход прокси**: программа подключилась напрямую, минуя прокси-клиент (не использует системный прокси, или
  соединение старше TUN). Карточка оповещения может запретить программе прямой выход (правило брандмауэра Windows
  только для внешних адресов; локальный порт прокси программе по-прежнему доступен) и позже снять запрет.

## Приватность: куда подключается MicaBar

Вся статистика (соединения, трафик, правила, оповещения) хранится только на этом ПК в `%LOCALAPPDATA%\MicaBar\`.
Сам MicaBar делает только такие запросы:

| Назначение | Адрес | Когда |
| --- | --- | --- |
| Выходной IP через прокси | ipinfo.io → api.ipify.org → ifconfig.me (через локальный порт прокси; выходы групп — через loopback-порт каждой группы) | при запуске, смене сети / прокси, каждые 5 мин |
| Прямой выходной IP | 4.ipw.cn → myip.ipip.net → ip.3322.net (с привязкой к физическому адаптеру; имена через 223.5.5.5 / 119.29.29.29) | так же |
| Тип и владелец IP | proxycheck.io (HTTPS) и ip-api.com (бесплатно только HTTP), каждый выходной IP (и прямой тоже) в запросе; через локальный порт прокси-клиента | при появлении нового выходного IP; кэш 24 ч на IP; отключается в Настройки → Сеть |
| Задержка узлов | измеряет ядро mihomo по `www.gstatic.com/generate_204` | каждые 15–60 с (профиль ресурсов) |
| Список gfw | cdn.jsdelivr.net / raw.githubusercontent.com (Loyalsoldier/v2ray-rules-dat) | раз в день, если включено |
| Проверка обновлений | latest.json из github.com/aileboeth/MicaBar | раз в день, если включено |
| Лимиты AI | api.anthropic.com (Claude Code), chatgpt.com (Codex), cli-chat-proxy.grok.com (Grok), локальный языковой сервер Antigravity | каждые 10 мин (настраивается), если включено; всегда через локальный порт прокси-клиента, напрямую никогда (нет порта — нет запроса) |
| Диагностика сети | напрямую: HTTP-API разрешения имён 119.29.29.29 / 223.5.5.5 (запрос qq.com); через прокси: `www.gstatic.com/generate_204`; DNS: свежий запрос www.baidu.com через системный DNS; полная проверка также пингует роутер | если включено: один маленький запрос каждые 10 с (напрямую), каждые 30 с через прокси и к DNS; полная проверка — только при сбоях |

Страна / ASN определяются по офлайн-базам из комплекта прокси-клиента (`country.mmdb`, `ASN.mmdb`); IP соединений
никуда не отправляются. Лимиты AI используют вход, который каждый инструмент хранит на этом ПК, и отправляют его
только в собственный сервис этого инструмента; он не сохраняется, не пишется в журнал и не продлевается. «Сейчас
играет» читает медиа-управление Windows и не обращается к сети. Уведомления тоже не обращаются к сети: уведомления за
день хранятся только в памяти, текст сообщений не пишется ни на диск, ни в журнал (и по умолчанию не показывается на
острове); loopback-порт `127.0.0.1:47900` принимает только вызовы хуков AI с токеном. Секрет контроллера mihomo
читается из его конфигурации во время работы и нигде не сохраняется и не передаётся.

История буфера обмена не ходит в сеть: записи хранятся только на этом ПК (`%LOCALAPPDATA%\MicaBar\clipboard`, зашифровано) или в памяти и не попадают в журнал.

## Сборка из исходников

Нужны Rust (rustup), Visual Studio C++ Build Tools, Node.js + pnpm.

```powershell
pnpm install
pnpm build            # один exe: src-tauri\target\release\micabar.exe
pnpm release          # установщик + портативная + манифест обновлений -> dist\release-<версия>\ (нужен keys\micabar.key)
```

Структура: `src-tauri\src\` (бэкенд на Rust: таблицы сокетов, ETW, контроллер mihomo, проверка выходов, защита от
утечек, поведение окна, захват для стекла…), `ui\` (чистые HTML / CSS / JS без сборщика; `ui\i18n\` — переводы,
ключами служит китайский исходный текст в коде), `tools\` (скрипт выпуска, драйвер тестовой ВМ).
Заметки о реализации (на китайском): [docs/internals.zh-CN.md](docs/internals.zh-CN.md).

## Отказ от ответственности

MicaBar — бесплатная программа с открытым кодом, которую автор делает в свободное время; она предоставляется «как
есть», без каких-либо гарантий. Она читает сетевые соединения, процессы, системные уведомления и состояние входа
AI-инструментов на этом ПК; эти данные используются только на этом ПК. Управление выходом и защита от утечек меняют
переопределение прокси-клиента, добавляют правила брандмауэра и могут перезапускать прокси-клиент. Автор не отвечает
за ущерб от использования программы или невозможности её использовать (потеря данных, обрывы сети, ограничение
аккаунтов…). Пользуйтесь с соблюдением местных законов и условий каждого сервиса. MicaBar не связан с Clash, mihomo,
Anthropic, OpenAI, Google, xAI и другими упомянутыми проектами и компаниями; названия и товарные знаки принадлежат их
владельцам.
