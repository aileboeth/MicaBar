# MicaBar

[English](README.md) · [简体中文](README.zh-CN.md) · **繁體中文** · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

Windows 上的「靈動島」式網路監視器。螢幕頂部一顆磨砂玻璃膠囊，平時顯示出口 IP 和連線數；滑鼠停上去展開，
看每個程式在用什麼埠、連到哪裡、走的哪個代理節點，並且能直接指定它走代理還是直連。

## 功能

- **按分組看出口**：訂閱裡每個分組（預設代理、AI、串流……）各自的出口 IP 和所用節點，外加直連出口，帶國家、電信商 / ASN，以及 IP 的類型（家寬 / 商寬 / 機房 / 手機網路，被列為代理的另外標出）和歸屬（國內 IP 顯示中文電信商和省份）。
- **膠囊輪換顯示**：各分組出口、正在播放的歌（封面 + 歌名）、AI 額度、網速、節點延遲依次輪換，內容和間隔都可設定。
- **AI 額度**：Claude Code、Codex、Antigravity、Grok 的訂閱用量（5 小時 / 每週等）和重置時間，圓環中間是各家的圖示。
- **正在跑的 AI 任務**：Claude Code 幹活時膠囊最前面顯示專案名和已用時間，等你批准時變成橙色「等你確認」；
  展開的島頂上也有，點一下切到它的終端視窗。按 Esc 中斷、關掉終端都會自動消失。
- **斷網診斷**：後臺每 10 秒輕輕探一次，連著兩次不通就從網路卡一路查到節點（網路卡 → 路由器 → DNS → 網際網路 → 代理軟體 → 節點），
  膠囊最前面直接說是哪一環斷了（「DNS 壞了」「節點掛了」「寬頻斷了」……），點開給出修復按鈕：重新整理 DNS 快取、換一個能用的節點、
  重啟代理軟體等；網路恢復時提示斷了多久。系統代理被別的軟體關掉或改掉時也會提醒，一鍵恢復。
- **新程式聯網提醒**：程式第一次連上公網時在島上彈卡片，「允許」或「阻止聯網」（Windows 防火牆規則；開啟出口控制時連它走系統代理的流量也攔住）。
  第一次開啟先熟悉 10 分鐘常用程式，程式更新換了版本號目錄也認得出來；在「預警」頁可以隨時恢復。
- **通知**：微信、Telegram、郵件等程式來訊息，以及 Claude Code / Codex 完成任務或等你確認時，在島上提示：
  膠囊右邊一格程式圖示、膠囊裡一行提示、或展開成卡片，三種任選；通知頁按程式分組。預設不顯示訊息內容，
  只顯示程式和傳送人；支援勿擾、免打擾時段、按程式靜音，以及接管程式自己的彈窗。
- **每個程式的連線**：程式圖示、程序數、即時上下行，走代理的程式排在前面；每條連線的本地埠 → 網域 / IP、國家、電信商、節點、命中的規則。
- **出口控制**（Clash Party / Mihomo Party）：按程式、網域、主網域，或「僅這個程式訪問這個網域」選擇 代理 / 直連 / 攔截，
  即時生效，不重啟核心；「代理」使用的節點可在島上切換、測速。
- **洩漏預警**：本該走代理的網站直連了就報警（膠囊變紅 + 系統通知），可以提前攔截：
  規則漏網時強制走代理；程式繞過代理時一鍵用 Windows 防火牆禁止它直連。
- **網速 / 流量 / 節點**：網速曲線、按程式的「代理 / 直連」流量統計（今天、7 天、30 天）、節點延遲與丟包。
- **系統監控**：CPU / GPU / 記憶體按程式排行，可以結束程序；開機自啟的程式像工作管理員一樣開關。
- **桌面視窗**：平時只有島和系統匣圖示；桌面視窗裡是總覽（出口、網速、流量、延遲、預警、AI 額度、最活躍的程式）和全部設定。
- **好看也好用**：即時磨砂玻璃（白 / 黑，跟隨系統；背景一半亮一半暗時也自動保證文字看得清）、多套配色和自定義主題；膠囊 / 劉海 / 指示條三種外形，
  可停靠螢幕任意一邊；懸停或點選展開、穿透模式、自定義快速鍵、鍵盤操作；全屏遊戲時不打擾；流暢的動效，跟隨 Windows 的動畫設定。
- **10 種介面語言**：简体中文、繁體中文、English、日本語、한국어、Русский、Español、Português (Brasil)、Français、Deutsch，預設跟隨 Windows 顯示語言。

> 外觀和互動參考了 [fly-island](https://github.com/flyl1u/fly-island)，部分功能思路參考了
> [BrimDeck](https://github.com/MoFeng2223/BrimDeck)；程式碼全部獨立編寫。

## 安裝

在 [Releases](https://github.com/aileboeth/MicaBar/releases) 下載：

- `MicaBar_<版本>_x64-setup.exe`：安裝版，裝到 `C:\Program Files\MicaBar`，支援應用內自動更新；
- `MicaBar_<版本>_portable.exe`：便攜版，單個 exe，不能自動更新。

要求 Windows 10 2004+ / Windows 11（x64）和 WebView2 執行時（Windows 11 自帶；安裝版會自動安裝）。
程式需要管理員許可權（按程式統計網速要用核心 ETW 事件），啟動時會彈 UAC；開了「開機自啟」後用計劃任務啟動，不再彈。

## 怎麼用

第一次啟動時，島上會有一段半分鐘的新手教學，一步步演示下面這些操作；以後可以在 設定 → 關於 →「重新看教學」再看一遍。

### 展開和收起

| 操作 | 效果 |
| --- | --- |
| 滑鼠停在膠囊上約 0.5 秒 | 展開成面板（預設的「滑鼠停留」方式；停留時間在 設定 → 常規 → 互動 裡改） |
| 滑鼠移出面板 | 收起 |
| 點選膠囊 / 點外面 | 「點選」方式下展開 / 收起（在 設定 → 常規 → 互動 →「怎麼展開」裡切換） |
| `Ctrl+Alt+N` | 隨時展開 / 收起（快速鍵可以改，點設定裡的快速鍵框再按新組合） |
| `Esc` | 收起面板；在彈出的底部面板、選單裡先關掉它們 |

- 「滑鼠停留」方式下，收起的膠囊不擋點選：滑鼠在上面停著時膠囊會變透明，能看到下面被擋住的標籤頁，點下去的是下面的視窗。
- **穿透模式**：滑鼠完全碰不到島，只能用快速鍵開啟，適合不想被誤觸的時候。
- 全屏程式（遊戲、影片）在前景時，膠囊照常顯示但不會自動展開、也不擋點選；也可以設成完全隱藏。
- 可選「前景視窗最大化時縮成指示條」：最大化視窗在前景時膠囊變成一條細線，切走就變回來。

### 拖動、甩動和停靠

島可以停在螢幕上、下、左、右任意一條邊，也可以停在這條邊的左 / 中 / 右（或上 / 中 / 下）。

1. **抓起**：展開後在面板上**按住不動約 0.26 秒**（時長在 設定 → 常規 → 互動 →「長按多久抓起島」裡改），島就被抓起來了。
   收起時：**先按住 `Alt`，再長按膠囊**（按住 Alt 時膠囊不再透明，長按抓的是它而不是下面的視窗）。
2. **沿著邊甩**：抓起後往左或往右一甩再鬆手，島會滑到這條邊的左端、中間或右端停住。
3. **換一條邊**：抓起後往螢幕中間拉開，島會跟著滑鼠走；拖到另一條邊附近鬆手，就停在那條邊上。停在左右兩邊時，膠囊會變成豎著的劉海。

不想拖的話，在 設定 → 收起外觀 裡直接選停靠位置和這條邊上的位置。

### 調整大小

- 系統匣圖示右鍵 →「調整島的大小…」，或桌面視窗左下角「調整島的大小」，或 設定 → 收起外觀 / 展開外觀 →「在螢幕上拖動調整」：
  螢幕上的膠囊和面板會出現可拖動的邊框，直接拖邊緣改寬高，調好點「完成」（`Esc` 取消）。
- 也可以在 設定 → 收起外觀 / 展開外觀 裡用滑塊調：膠囊高度、寬度（0 = 跟著內容自動變寬）、面板寬度、最大高度、介面縮放。

### 鍵盤

面板展開時：`Tab` / `Shift+Tab` 按順序移動焦點；焦點在頂部頁面圖示或網路頁的頁簽上時 `←` / `→` 切換；
`↑` / `↓` 在列表的行和按鈕之間移動；`Enter` / `空格` 展開當前程式；`Esc` 收起。
設定裡可以拖動排序的列表，選中後按 `Alt+↑` / `Alt+↓` 也能調整順序。

### 面板裡的各個頁面

面板頂部這排圖示切換頁面（網路、系統、音樂、AI 額度、通知）；哪些頁面顯示、什麼順序在 設定 → 展開外觀 裡改，島會記住上次停在哪一頁。

**網路頁**

- 最上面是**出口卡片**：左邊是代理出口，每個出口 IP 一行，後面是 IP 類型標籤（家寬 / 商寬 / 機房 / 手機網路 / 被標代理），
  第二行是節點和歸屬；用這個 IP 的分組排在 IP 右邊，放不下的收成「+N」，點一下展開、再點「收起」。
  右邊是直連出口（電信商、網路卡、反查網域、上次檢測時間）。滑鼠停在 IP 或標籤上可以看註冊組織、接入商、ASN 和資料來源。
  右上角的 ↻ 立即重新檢測出口，旁邊的脈搏圖示開啟**網路診斷**。
- 出口卡片下面一行是代理軟體、系統代理、TUN、本地埠和控制介面的狀態。
- 頁籤：**連線 / 監聽 / 出口 / 預警 / 網速 / 流量 / 節點**（頁籤太多時可以用滑鼠滾輪左右滾動；順序可在設定裡拖動調整）。右邊的搜尋框按程式、網域、IP、埠過濾。
  - **連線**：每個正在聯網的程式一行（走代理的排前面）。點一行展開它的每條連線；行右邊的「出口」按鈕給整個程式選 代理 / 直連 / 攔截，
    連線右邊的「⋯」只管這條連線（這個網域、這個 IP，或「僅這個程式訪問它」）。再點一次已選中的按鈕 = 恢復按規則。
  - **監聽**：本機在監聽的埠，監聽所有網路卡（區域網能訪問）的會標出來。
  - **出口**：啟用 / 停用出口控制，檢視和刪除出口規則，切換「代理」用的節點並測速。
  - **預警**：代理洩漏和新程式聯網的記錄；可以「禁止它直連」、忽略某個網域、恢復聯網。
  - **網速**：即時網速曲線。滑鼠在圖上左右移動會吸附到每一秒，上方的大數字跟著變；點圖下面的某個程式，從底部拉出它自己的曲線和統計，
    這個底部面板可以上下拖動，往下一甩就關掉，裡面有「看它的連線」「在大圖裡只看它」。
  - **流量**：按程式統計「代理 / 直連」流量，今天 / 7 天 / 30 天切換；點柱狀圖的某一天看那一天的明細。
  - **節點**：每個出口節點的延遲和丟包曲線，「立即測速」馬上測一輪。
- **網路診斷**（脈搏圖示，或斷網時點膠囊上的紅色提示）：從網路卡一路查到節點，告訴你斷在哪一環，下面給出修復按鈕（重新整理 DNS 快取、恢復系統代理、開啟 / 重啟代理軟體、換一個能用的節點等）。

**系統頁**：CPU / GPU 每個核心的佔用、記憶體和影片記憶體；下面切換「佔用最多的程式」（按 CPU 或記憶體排序，點 ✕ 結束程序，會先確認；Windows 核心程序和 MicaBar 自己不會被結束）
和「開機自啟」（和工作管理員的「啟動應用」是同一個開關，關掉不刪除任何東西）。

**音樂頁**：正在播放的歌（網易雲、QQ 音樂、Spotify、瀏覽器裡的影片等），封面、歌名、隨音樂跳動的線條，上一首 / 播放暫停 / 下一首。

**AI 額度頁**：每個 AI 工具一張卡片，顯示各個額度視窗用了多少、什麼時候重置；「立即重新整理」馬上查一次（官方介面限流嚴，Claude 最少 10 分鐘查一次）。

**通知頁**：按程式分組；點一條開啟對應的程式，「全部已讀」「全部清除」；**右鍵**一組可以靜音這個程式或清除這一組。

### 膠囊上的提示

- 膠囊平時顯示的內容（出口 IP、網速、AI 額度圓環、時鐘、CPU / 記憶體……）在 設定 → 收起外觀 →「顯示內容」裡勾選、拖動排序；
  寬度放不下的幾項會合到最後一格輪流顯示。
- 斷網、系統代理被改、Claude Code 在幹活或等你批准時，相應的提示會出現在膠囊最前面，點一下就開啟診斷或切到對應的終端。
- 出口 IP 變了、節點無響應或延遲變高、網速突增時，膠囊上會短暫提示 5 秒（在 設定 → 網路 →「短暫提示」裡開關和改閾值）。
- 有洩漏時膠囊變紅；有未讀通知時右邊出現程式圖示和紅點。

### 桌面視窗、設定和系統匣

- **左鍵點系統匣圖示**或面板右上角的**齒輪**開啟桌面視窗：總覽、連線、監聽埠、出口控制、洩漏預警、網速、流量、節點、系統監控、AI 額度、通知和設定。
- **右鍵系統匣圖示**：開啟 MicaBar、設定、調整島的大小、重新檢測出口 IP、外觀（跟隨系統 / 白色磨砂 / 黑色磨砂）、開啟記錄檔、退出。
- 設定按分類放在左側欄（基礎設定：常規、收起外觀、展開外觀、面板主題；網路；AI 用量；音樂；通知；關於），每一項都能開關；
  外形和主題看著預覽卡片選；帶 ⠿ 的列表直接拖動排序。最下面可以把所有設定恢復預設。
- **介面語言**：設定 → 常規 →「語言」，預設「跟隨系統」（按 Windows 顯示語言）；改完所有視窗會重新整理一下，系統匣選單也跟著換。

## 分組出口

啟用出口控制後，覆寫會給每個代理分組開一個只監聽本機的埠（`127.0.0.1:47800` 起），從這個埠進來的流量直接交給
對應分組。MicaBar 從各埠分別查一次出口 IP，就知道「預設代理」「AI」「YouTube」各自從哪裡出去。預設顯示兜底分組 +
最近有流量的分組（最多 4 個），也可以在設定裡手動勾選。

## 出口控制

第一次檢測到 Clash Party / Mihomo Party 時，島上會提示啟用。啟用會：備份 Clash Party 的覆寫列表，加一個全域性覆寫
「MicaBar 出口控制」，並重啟 Clash Party 一次（斷網約 3 秒）；載入失敗會自動還原。之後在程式右邊的「出口」
或連線右邊的「⋯」裡選擇即可。更具體的規則優先：「整個程式直連」+「僅它訪問 *.example.com 走代理」兩條可以同時生效。
在「出口」頁底部可以停用並移除覆寫。

系統代理模式下只能管住遵守系統代理的程式；要管住所有程式請開啟 TUN。

## 支援的代理軟體

| 代理軟體 | 代理出口 / 本地埠 | 節點、分組、命中規則 | 出口控制 / 提前攔截 |
|---|---|---|---|
| Clash Party / Mihomo Party | ✓ | ✓ | ✓ |
| Clash Verge Rev | ✓ | ✓（透過它的控制介面） | — |
| v2rayN、Throne（NekoRay）、Hiddify、FlClash、Karing | ✓（系統代理埠，或它們常用的本地埠） | — | — |

系統代理、TUN 網路卡和每個程式的連線與代理軟體無關，都能顯示。

## 通知

通知來自三個地方，全部在本機讀取：

- **工作列閃爍**：微信 4.x 來訊息時只閃工作列、不發系統通知，視窗內容也讀不到，所以只能提示「微信 · N 條新訊息」，點一下開啟微信；其他閃工作列的程式同理。
- **程式自己的彈窗 / 系統通知**：Telegram 關掉系統通知後會在右下角彈自己的小窗，MicaBar 看到小窗時讀一次它主視窗的會話列表（Windows 無障礙介面），找出新訊息數增加的會話；走 Windows 系統通知的程式從系統的通知資料庫讀取。勾選「接管彈窗」後，程式自己（或 Windows）的彈窗不再出現，只在島上提示。
- 走 Windows 系統通知的程式（WhatsApp、Teams、Slack、Discord、Signal、Zoom、LINE 等）顯示它們自己的名字和圖示；同一條訊息既閃工作列又發通知時只算一條。
- 開啟發通知的程式就算已讀，紅點自動消失；通知到達時你正在用這個程式，就不再提示。
- **AI 完成提醒**：在 設定 → 通知 裡點「接入」，會往 Claude Code 的 `~/.claude/settings.json` 或 Codex 的 `~/.codex/config.toml` 加一個鉤子（改之前自動備份，可一鍵移除）：任務完成或等你批准時，用 `curl` 通知本機 `127.0.0.1:47900`（帶隨機口令）。

## 洩漏預警

「應走代理」規則庫 = 內建常見服務清單（約 140 個主網域）+ 訂閱 gfw 列表（每天更新）+ 自定義 / 匯入（支援純網域、
v2fly、Clash 規則格式）。兩種洩漏：

- **規則漏網**：經過了代理軟體，但被分流規則判成直連。開啟「提前攔截」後，這類網域在落進直連規則之前就被轉到代理，
  訂閱裡按服務分好的分組不受影響。
- **繞過代理**：程式沒經過代理軟體直接連了出去（不走系統代理，或連線早於 TUN）。預警卡上可以一鍵
  「禁止 xxx 直連」（Windows 防火牆規則，只攔公網地址，程式仍能透過本機代理埠上網），可隨時解除。

## 隱私：MicaBar 會連線哪些地方

所有統計（連線、流量、規則、預警記錄）都只存在本機 `%LOCALAPPDATA%\MicaBar\`。程式主動發起的網路請求只有：

| 用途 | 地址 | 時機 |
| --- | --- | --- |
| 代理出口 IP | ipinfo.io → api.ipify.org → ifconfig.me（經本地代理埠；分組出口經各分組的本機埠） | 啟動、網路 / 代理變化、每 5 分鐘 |
| 直連出口 IP | 4.ipw.cn → myip.ipip.net → ip.3322.net（繫結物理網路卡；網域經 223.5.5.5 / 119.29.29.29 解析） | 同上 |
| IP 類型和歸屬 | proxycheck.io（HTTPS）和 ip-api.com（免費版只有 HTTP），把各個出口 IP（包括直連出口）作為查詢引數發過去；經代理軟體的本地埠 | 出現新的出口 IP 時；同一個 IP 快取 24 小時；設定 → 網路裡可以關 |
| 節點延遲 | 由 mihomo 核心測 `www.gstatic.com/generate_204` | 15~60 秒一次（資源檔位） |
| gfw 列表 | cdn.jsdelivr.net / raw.githubusercontent.com（Loyalsoldier/v2ray-rules-dat） | 開啟時每天一次 |
| 檢查更新 | github.com/aileboeth/MicaBar 的 latest.json | 開啟時每天一次 |
| AI 額度 | api.anthropic.com（Claude Code）、chatgpt.com（Codex）、cli-chat-proxy.grok.com（Grok）、本機的 Antigravity 語言伺服器 | 開啟時每 10 分鐘（可改）；一律經代理軟體的本地埠發出，絕不直連（找不到埠就不查） |
| 斷網診斷 | 直連：119.29.29.29 / 223.5.5.5 的 HTTP 解析介面（查 qq.com）；經代理：`www.gstatic.com/generate_204`；DNS：經系統 DNS 解析 www.baidu.com（不用快取）；診斷時再 ping 路由器 | 開啟時直連每 10 秒、經代理和 DNS 每 30 秒各一次；不通時才做完整診斷 |

國家 / ASN 用的是代理客戶端自帶的離線庫（`country.mmdb`、`ASN.mmdb`），不會把連線的 IP 發給任何服務。
AI 額度用各工具在本機已登入的憑據，只發給那個工具自己的服務，不儲存、不寫記錄檔、不續期。
正在播放讀的是 Windows 媒體控制介面，不聯網。
通知不聯網：只在記憶體裡儲存當天的通知，訊息內容不寫硬碟、不寫記錄檔，預設也不在島上顯示；本機埠 `127.0.0.1:47900` 只接收帶口令的 AI 鉤子呼叫。
mihomo 控制介面的金鑰只在執行時從配置檔案讀取，不會儲存或外傳。

## 從原始碼編譯

需要 Rust（rustup）、Visual Studio C++ Build Tools、Node.js + pnpm。

```powershell
pnpm install
pnpm build            # 單個 exe：src-tauri\target\release\micabar.exe
pnpm release          # 安裝包 + 便攜版 + 自動更新清單 -> dist\release-<版本>\（需要更新簽名私鑰 keys\micabar.key）
```

原始碼結構：`src-tauri\src\`（Rust 後端：連線表、ETW、mihomo 控制介面、出口檢測、守衛、視窗控制、磨砂截圖……），
`ui\`（無需打包的純 HTML / CSS / JS 前端；`ui\i18n\` 是各語言的翻譯，程式碼裡的中文原文就是翻譯的鍵），`tools\`（釋出指令碼、測試虛擬機器驅動）。
實現細節見 [docs/internals.zh-CN.md](docs/internals.zh-CN.md)。
