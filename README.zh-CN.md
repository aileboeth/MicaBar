# MicaBar

[English](README.md) · **简体中文** · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

Windows 上的「灵动岛」式网络监视器。屏幕顶部一颗磨砂玻璃胶囊，平时显示出口 IP 和连接数；鼠标停上去展开，
看每个程序在用什么端口、连到哪里、走的哪个代理节点，并且能直接指定它走代理还是直连。

## 功能

- **按分组看出口**：订阅里每个分组（默认代理、AI、流媒体……）各自的出口 IP 和所用节点，外加直连出口，带国家、运营商 / ASN，以及 IP 的类型（家宽 / 商宽 / 机房 / 手机网络，被列为代理的另外标出）和归属（国内 IP 显示中文运营商和省份）。
- **胶囊轮换显示**：各分组出口、正在播放的歌（封面 + 歌名）、AI 额度、网速、节点延迟依次轮换，内容和间隔都可设置。
- **AI 额度**：Claude Code、Codex、Antigravity、Grok 的订阅用量（5 小时 / 每周等）和重置时间，圆环中间是各家的图标。
- **正在跑的 AI 任务**：Claude Code 干活时胶囊最前面显示项目名和已用时间，等你批准时变成橙色「等你确认」；
  展开的岛顶上也有，点一下切到它的终端窗口。按 Esc 中断、关掉终端都会自动消失。
- **断网诊断**：后台每 10 秒轻轻探一次，连着两次不通就从网卡一路查到节点（网卡 → 路由器 → DNS → 互联网 → 代理软件 → 节点），
  胶囊最前面直接说是哪一环断了（「DNS 坏了」「节点挂了」「宽带断了」……），点开给出修复按钮：刷新 DNS 缓存、换一个能用的节点、
  重启代理软件等；网络恢复时提示断了多久。系统代理被别的软件关掉或改掉时也会提醒，一键恢复。
- **新程序联网提醒**：程序第一次连上公网时在岛上弹卡片，「允许」或「阻止联网」（Windows 防火墙规则；开启出口控制时连它走系统代理的流量也拦住）。
  第一次开启先熟悉 10 分钟常用程序，程序更新换了版本号目录也认得出来；在「预警」页可以随时恢复。
- **通知**：微信、Telegram、邮件等程序来消息，以及 Claude Code / Codex 完成任务或等你确认时，在岛上提示：
  胶囊右边一格程序图标、胶囊里一行提示、或展开成卡片，三种任选；通知页按程序分组。默认不显示消息内容，
  只显示程序和发送人；支持勿扰、免打扰时段、按程序静音，以及接管程序自己的弹窗。
- **每个程序的连接**：程序图标、进程数、实时上下行，走代理的程序排在前面；每条连接的本地端口 → 域名 / IP、国家、运营商、节点、命中的规则。
- **出口控制**（Clash Party / Mihomo Party）：按程序、域名、主域，或「仅这个程序访问这个域名」选择 代理 / 直连 / 拦截，
  即时生效，不重启内核；「代理」使用的节点可在岛上切换、测速。
- **泄漏预警**：本该走代理的网站直连了就报警（胶囊变红 + 系统通知），可以提前拦截：
  规则漏网时强制走代理；程序绕过代理时一键用 Windows 防火墙禁止它直连。
- **网速 / 流量 / 节点**：网速曲线、按程序的「代理 / 直连」流量统计（今天、7 天、30 天）、节点延迟与丢包。
- **系统监控**：CPU / GPU / 内存按程序排行，可以结束进程；开机自启的程序像任务管理器一样开关。
- **桌面窗口**：平时只有岛和托盘图标；桌面窗口里是总览（出口、网速、流量、延迟、预警、AI 额度、最活跃的程序）和全部设置。
- **好看也好用**：实时磨砂玻璃（白 / 黑，跟随系统；背景一半亮一半暗时也自动保证文字看得清）、多套配色和自定义主题；胶囊 / 刘海 / 指示条三种外形，
  可停靠屏幕任意一边；悬停或点击展开、穿透模式、自定义快捷键、键盘操作；全屏游戏时不打扰；流畅的动效，跟随 Windows 的动画设置。
- **10 种界面语言**：简体中文、繁體中文、English、日本語、한국어、Русский、Español、Português (Brasil)、Français、Deutsch，默认跟随 Windows 显示语言。
- **剪贴板历史**：复制过的文字和图片收在岛上的「剪贴板」页里，点一条就复制回剪贴板；可以搜索、置顶，按天数和条数自动清理，密码管理器标记为隐私的内容不记录。

> 外观和交互参考了 [fly-island](https://github.com/flyl1u/fly-island)，部分功能思路参考了
> [BrimDeck](https://github.com/MoFeng2223/BrimDeck)；代码全部独立编写。

## 安装

在 [Releases](https://github.com/aileboeth/MicaBar/releases) 下载：

- `MicaBar_<版本>_x64-setup.exe`：安装版，装到 `C:\Program Files\MicaBar`，支持应用内自动更新；
- `MicaBar_<版本>_portable.exe`：便携版，单个 exe，不能自动更新。

要求 Windows 10 2004+ / Windows 11（x64）和 WebView2 运行时（Windows 11 自带；安装版会自动安装）。
程序需要管理员权限（按程序统计网速要用内核 ETW 事件），启动时会弹 UAC；开了「开机自启」后用计划任务启动，不再弹。

## 怎么用

第一次启动时，岛上会有一段半分钟的新手教程，一步步演示下面这些操作；以后可以在 设置 → 关于 →「重新看教程」再看一遍。

### 展开和收起

| 操作 | 效果 |
| --- | --- |
| 鼠标停在胶囊上约 0.5 秒 | 展开成面板（默认的「鼠标停留」方式；停留时间在 设置 → 常规 → 交互 里改） |
| 鼠标移出面板 | 收起 |
| 点击胶囊 / 点外面 | 「点击」方式下展开 / 收起（在 设置 → 常规 → 交互 →「怎么展开」里切换） |
| `Ctrl+Alt+N` | 随时展开 / 收起（快捷键可以改，点设置里的快捷键框再按新组合） |
| `Esc` | 收起面板；在弹出的底部面板、菜单里先关掉它们 |

- 「鼠标停留」方式下，收起的胶囊不挡点击：鼠标在上面停着时胶囊会变透明，能看到下面被挡住的标签页，点下去的是下面的窗口。
- **穿透模式**：鼠标完全碰不到岛，只能用快捷键打开，适合不想被误触的时候。
- 全屏程序（游戏、视频）在前台时，胶囊照常显示但不会自动展开、也不挡点击；也可以设成完全隐藏。
- 可选「前台窗口最大化时缩成指示条」：最大化窗口在前台时胶囊变成一条细线，切走就变回来。

### 拖动、甩动和停靠

岛可以停在屏幕上、下、左、右任意一条边，也可以停在这条边的左 / 中 / 右（或上 / 中 / 下）。

1. **抓起**：展开后在面板上**按住不动约 0.26 秒**（时长在 设置 → 常规 → 交互 →「长按多久抓起岛」里改），岛就被抓起来了。
   收起时：**先按住 `Alt`，再长按胶囊**（按住 Alt 时胶囊不再透明，长按抓的是它而不是下面的窗口）。
2. **沿着边甩**：抓起后往左或往右一甩再松手，岛会滑到这条边的左端、中间或右端停住。
3. **换一条边**：抓起后往屏幕中间拉开，岛会跟着鼠标走；拖到另一条边附近松手，就停在那条边上。停在左右两边时，胶囊会变成竖着的刘海。

不想拖的话，在 设置 → 收起外观 里直接选停靠位置和这条边上的位置。

### 调整大小

- 托盘图标右键 →「调整岛的大小…」，或桌面窗口左下角「调整岛的大小」，或 设置 → 收起外观 / 展开外观 →「在屏幕上拖动调整」：
  屏幕上的胶囊和面板会出现可拖动的边框，直接拖边缘改宽高，调好点「完成」（`Esc` 取消）。
- 也可以在 设置 → 收起外观 / 展开外观 里用滑块调：胶囊高度、宽度（0 = 跟着内容自动变宽）、面板宽度、最大高度、界面缩放。

### 键盘

面板展开时：`Tab` / `Shift+Tab` 按顺序移动焦点；焦点在顶部页面图标或网络页的页签上时 `←` / `→` 切换；
`↑` / `↓` 在列表的行和按钮之间移动；`Enter` / `空格` 展开当前程序；`Esc` 收起。
设置里可以拖动排序的列表，选中后按 `Alt+↑` / `Alt+↓` 也能调整顺序。

### 面板里的各个页面

面板顶部这排图标切换页面（网络、系统、音乐、AI 额度、通知）；哪些页面显示、什么顺序在 设置 → 展开外观 里改，岛会记住上次停在哪一页。

**网络页**

- 最上面是**出口卡片**：左边是代理出口，每个出口 IP 一行，后面是 IP 类型标签（家宽 / 商宽 / 机房 / 手机网络 / 被标代理），
  第二行是节点和归属；用这个 IP 的分组排在 IP 右边，放不下的收成「+N」，点一下展开、再点「收起」。
  右边是直连出口（运营商、网卡、反查域名、上次检测时间）。鼠标停在 IP 或标签上可以看注册组织、接入商、ASN 和数据来源。
  右上角的 ↻ 立即重新检测出口，旁边的脉搏图标打开**网络诊断**。
- 出口卡片下面一行是代理软件、系统代理、TUN、本地端口和控制接口的状态。
- 页签：**连接 / 监听 / 出口 / 预警 / 网速 / 流量 / 节点**（页签太多时可以用鼠标滚轮左右滚动；顺序可在设置里拖动调整）。右边的搜索框按程序、域名、IP、端口过滤。
  - **连接**：每个正在联网的程序一行（走代理的排前面）。点一行展开它的每条连接；行右边的「出口」按钮给整个程序选 代理 / 直连 / 拦截，
    连接右边的「⋯」只管这条连接（这个域名、这个 IP，或「仅这个程序访问它」）。再点一次已选中的按钮 = 恢复按规则。
  - **监听**：本机在监听的端口，监听所有网卡（局域网能访问）的会标出来。
  - **出口**：启用 / 停用出口控制，查看和删除出口规则，切换「代理」用的节点并测速。
  - **预警**：代理泄漏和新程序联网的记录；可以「禁止它直连」、忽略某个域名、恢复联网。
  - **网速**：实时网速曲线。鼠标在图上左右移动会吸附到每一秒，上方的大数字跟着变；点图下面的某个程序，从底部拉出它自己的曲线和统计，
    这个底部面板可以上下拖动，往下一甩就关掉，里面有「看它的连接」「在大图里只看它」。
  - **流量**：按程序统计「代理 / 直连」流量，今天 / 7 天 / 30 天切换；点柱状图的某一天看那一天的明细。
  - **节点**：每个出口节点的延迟和丢包曲线，「立即测速」马上测一轮。
- **网络诊断**（脉搏图标，或断网时点胶囊上的红色提示）：从网卡一路查到节点，告诉你断在哪一环，下面给出修复按钮（刷新 DNS 缓存、恢复系统代理、打开 / 重启代理软件、换一个能用的节点等）。

**系统页**：CPU / GPU 每个核心的占用、内存和显存；下面切换「占用最多的程序」（按 CPU 或内存排序，点 ✕ 结束进程，会先确认；Windows 核心进程和 MicaBar 自己不会被结束）
和「开机自启」（和任务管理器的「启动应用」是同一个开关，关掉不删除任何东西）。

**音乐页**：正在播放的歌（网易云、QQ 音乐、Spotify、浏览器里的视频等），封面、歌名、随音乐跳动的线条，上一首 / 播放暂停 / 下一首。

**AI 额度页**：每个 AI 工具一张卡片，显示各个额度窗口用了多少、什么时候重置；「立即刷新」马上查一次（官方接口限流严，Claude 最少 10 分钟查一次）。

**通知页**：按程序分组；点一条打开对应的程序，「全部已读」「全部清除」；**右键**一组可以静音这个程序或清除这一组。

### 胶囊上的提示

- 胶囊平时显示的内容（出口 IP、网速、AI 额度圆环、时钟、CPU / 内存……）在 设置 → 收起外观 →「显示内容」里勾选、拖动排序；
  宽度放不下的几项会合到最后一格轮流显示。
- 断网、系统代理被改、Claude Code 在干活或等你批准时，相应的提示会出现在胶囊最前面，点一下就打开诊断或切到对应的终端。
- 出口 IP 变了、节点无响应或延迟变高、网速突增时，胶囊上会短暂提示 5 秒（在 设置 → 网络 →「短暂提示」里开关和改阈值）。
- 有泄漏时胶囊变红；有未读通知时右边出现程序图标和红点。

### 桌面窗口、设置和托盘

- **左键点托盘图标**或面板右上角的**齿轮**打开桌面窗口：总览、连接、监听端口、出口控制、泄漏预警、网速、流量、节点、系统监控、AI 额度、通知和设置。
- **右键托盘图标**：打开 MicaBar、设置、调整岛的大小、重新检测出口 IP、外观（跟随系统 / 白色磨砂 / 黑色磨砂）、打开日志、退出。
- 设置按分类放在左侧栏（基础设置：常规、收起外观、展开外观、面板主题；网络；AI 用量；音乐；通知；关于），每一项都能开关；
  外形和主题看着预览卡片选；带 ⠿ 的列表直接拖动排序。最下面可以把所有设置恢复默认。
- **界面语言**：设置 → 常规 →「语言」，默认「跟随系统」（按 Windows 显示语言）；改完所有窗口会刷新一下，托盘菜单也跟着换。

## 分组出口

启用出口控制后，覆写会给每个代理分组开一个只监听本机的端口（`127.0.0.1:47800` 起），从这个端口进来的流量直接交给
对应分组。MicaBar 从各端口分别查一次出口 IP，就知道「默认代理」「AI」「YouTube」各自从哪里出去。默认显示兜底分组 +
最近有流量的分组（最多 4 个），也可以在设置里手动勾选。

## 出口控制

第一次检测到 Clash Party / Mihomo Party 时，岛上会提示启用。启用会：备份 Clash Party 的覆写列表，加一个全局覆写
「MicaBar 出口控制」，并重启 Clash Party 一次（断网约 3 秒）；加载失败会自动还原。之后在程序右边的「出口」
或连接右边的「⋯」里选择即可。更具体的规则优先：「整个程序直连」+「仅它访问 *.example.com 走代理」两条可以同时生效。
在「出口」页底部可以停用并移除覆写。

系统代理模式下只能管住遵守系统代理的程序；要管住所有程序请开启 TUN。

## 支持的代理软件

| 代理软件 | 代理出口 / 本地端口 | 节点、分组、命中规则 | 出口控制 / 提前拦截 |
|---|---|---|---|
| Clash Party / Mihomo Party | ✓ | ✓ | ✓ |
| Clash Verge Rev | ✓ | ✓（通过它的控制接口） | — |
| v2rayN、Throne（NekoRay）、Hiddify、FlClash、Karing | ✓（系统代理端口，或它们常用的本地端口） | — | — |

系统代理、TUN 网卡和每个程序的连接与代理软件无关，都能显示。

## 通知

通知来自三个地方，全部在本机读取：

- **任务栏闪烁**：微信 4.x 来消息时只闪任务栏、不发系统通知，窗口内容也读不到，所以只能提示「微信 · N 条新消息」，点一下打开微信；其他闪任务栏的程序同理。
- **程序自己的弹窗 / 系统通知**：Telegram 关掉系统通知后会在右下角弹自己的小窗，MicaBar 看到小窗时读一次它主窗口的会话列表（Windows 无障碍接口），找出新消息数增加的会话；走 Windows 系统通知的程序从系统的通知数据库读取。勾选「接管弹窗」后，程序自己（或 Windows）的弹窗不再出现，只在岛上提示。
- 走 Windows 系统通知的程序（WhatsApp、Teams、Slack、Discord、Signal、Zoom、LINE 等）显示它们自己的名字和图标；同一条消息既闪任务栏又发通知时只算一条。
- 打开发通知的程序就算已读，红点自动消失；通知到达时你正在用这个程序，就不再提示。
- **AI 完成提醒**：在 设置 → 通知 里点「接入」，会往 Claude Code 的 `~/.claude/settings.json` 或 Codex 的 `~/.codex/config.toml` 加一个钩子（改之前自动备份，可一键移除）：任务完成或等你批准时，用 `curl` 通知本机 `127.0.0.1:47900`（带随机口令）。

## 剪贴板历史

- 复制过的文字和图片（截图等）按时间收在面板的「剪贴板」页里，置顶的排在最上面；同样的内容再复制一次只会移到最上面，不会重复。
- 点一条只把它复制回剪贴板，粘贴还是自己按 Ctrl+V；鼠标停在一条上时右上角可以置顶或删除，顶部可以搜索。
- 设置 → 剪贴板 里可以选：是否记录图片、保存在本机硬盘（用当前 Windows 账户的密钥加密，重启后还在）还是只在内存、保留多少天、最多多少条；置顶的永远不会被自动删除。
- Bitwarden、KeePass、1Password 等密码管理器复制密码时会给内容加「不要记录」的标记，这类内容默认跳过。
- 胶囊右边有个剪贴板图标，复制新内容时会跳一下（设置 → 收起外观 里可以关掉）。

## 泄漏预警

「应走代理」规则库 = 内置常见服务清单（约 140 个主域）+ 订阅 gfw 列表（每天更新）+ 自定义 / 导入（支持纯域名、
v2fly、Clash 规则格式）。两种泄漏：

- **规则漏网**：经过了代理软件，但被分流规则判成直连。开启「提前拦截」后，这类域名在落进直连规则之前就被转到代理，
  订阅里按服务分好的分组不受影响。
- **绕过代理**：程序没经过代理软件直接连了出去（不走系统代理，或连接早于 TUN）。预警卡上可以一键
  「禁止 xxx 直连」（Windows 防火墙规则，只拦公网地址，程序仍能通过本机代理端口上网），可随时解除。

## 隐私：MicaBar 会连接哪些地方

所有统计（连接、流量、规则、预警记录）都只存在本机 `%LOCALAPPDATA%\MicaBar\`。程序主动发起的网络请求只有：

| 用途 | 地址 | 时机 |
| --- | --- | --- |
| 代理出口 IP | ipinfo.io → api.ipify.org → ifconfig.me（经本地代理端口；分组出口经各分组的本机端口） | 启动、网络 / 代理变化、每 5 分钟 |
| 直连出口 IP | 4.ipw.cn → myip.ipip.net → ip.3322.net（绑定物理网卡；域名经 223.5.5.5 / 119.29.29.29 解析） | 同上 |
| IP 类型和归属 | proxycheck.io（HTTPS）和 ip-api.com（免费版只有 HTTP），把各个出口 IP（包括直连出口）作为查询参数发过去；经代理软件的本地端口 | 出现新的出口 IP 时；同一个 IP 缓存 24 小时；设置 → 网络里可以关 |
| 节点延迟 | 由 mihomo 内核测 `www.gstatic.com/generate_204` | 15~60 秒一次（资源档位） |
| gfw 列表 | cdn.jsdelivr.net / raw.githubusercontent.com（Loyalsoldier/v2ray-rules-dat） | 开启时每天一次 |
| 检查更新 | github.com/aileboeth/MicaBar 的 latest.json | 开启时每天一次 |
| AI 额度 | api.anthropic.com（Claude Code）、chatgpt.com（Codex）、cli-chat-proxy.grok.com（Grok）、本机的 Antigravity 语言服务器 | 开启时每 10 分钟（可改）；一律经代理软件的本地端口发出，绝不直连（找不到端口就不查） |
| 断网诊断 | 直连：119.29.29.29 / 223.5.5.5 的 HTTP 解析接口（查 qq.com）；经代理：`www.gstatic.com/generate_204`；DNS：经系统 DNS 解析 www.baidu.com（不用缓存）；诊断时再 ping 路由器 | 开启时直连每 10 秒、经代理和 DNS 每 30 秒各一次；不通时才做完整诊断 |

国家 / ASN 用的是代理客户端自带的离线库（`country.mmdb`、`ASN.mmdb`），不会把连接的 IP 发给任何服务。
AI 额度用各工具在本机已登录的凭据，只发给那个工具自己的服务，不保存、不写日志、不续期。
正在播放读的是 Windows 媒体控制接口，不联网。
通知不联网：只在内存里保存当天的通知，消息内容不写硬盘、不写日志，默认也不在岛上显示；本机端口 `127.0.0.1:47900` 只接收带口令的 AI 钩子调用。
mihomo 控制接口的密钥只在运行时从配置文件读取，不会保存或外传。

剪贴板历史不联网：记录只在本机（`%LOCALAPPDATA%\MicaBar\clipboard`，加密）或内存里，不写日志。

## 从源码编译

需要 Rust（rustup）、Visual Studio C++ Build Tools、Node.js + pnpm。

```powershell
pnpm install
pnpm build            # 单个 exe：src-tauri\target\release\micabar.exe
pnpm release          # 安装包 + 便携版 + 自动更新清单 -> dist\release-<版本>\（需要更新签名私钥 keys\micabar.key）
```

源码结构：`src-tauri\src\`（Rust 后端：连接表、ETW、mihomo 控制接口、出口检测、守卫、窗口控制、磨砂截屏……），
`ui\`（无需打包的纯 HTML / CSS / JS 前端；`ui\i18n\` 是各语言的翻译，代码里的中文原文就是翻译的键），`tools\`（发布脚本、测试虚拟机驱动）。
实现细节见 [docs/internals.zh-CN.md](docs/internals.zh-CN.md)。
