# MicaBar

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md) · [Русский](README.ru.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

Windows 用の「ダイナミックアイランド」風ネットワークモニターです。画面上部のすりガラスのカプセルが普段は出口 IP と接続数を表示し、
マウスを置くと展開して、どのアプリがどのポートを使い、どこへ接続し、どのプロキシノードを通っているかが分かります。
その場でプロキシ経由か直結かを指定することもできます。

## 機能

- **グループ別の出口**：サブスクリプションの各グループ（既定のプロキシ、AI、動画配信…）の出口 IP と使用ノード、さらに直結の出口。
  国、接続事業者 / ASN に加え、IP の種類（家庭用 / 法人 / データセンター / モバイル、プロキシとして登録されているものは別表示）と所属（中国本土の IP はキャリアと省）も表示します。
- **カプセルのローテーション表示**：各グループの出口、再生中の曲（ジャケット + 曲名）、AI 使用量、速度、ノード遅延が順に切り替わります。内容と間隔は設定できます。
- **AI 使用量**：Claude Code、Codex、Antigravity、Grok のサブスクリプション使用量（5 時間 / 毎週など）とリセット時刻。リングの中央に各ツールのアイコン。
- **実行中の AI タスク**：Claude Code が作業中はカプセルの先頭にプロジェクト名と経過時間を表示し、承認待ちになるとオレンジ色になります。
  展開したアイランドの上部にも表示され、クリックでそのターミナルへ切り替えます。Esc で中断したりターミナルを閉じたりすると消えます。
- **切断の診断**：バックグラウンドで 10 秒ごとに軽く確認し、2 回続けて失敗するとアダプター → ルーター → DNS → インターネット → プロキシアプリ → ノードの順に調べます。
  どこが切れたか（「DNS 障害」「ノード停止」「回線断」…）をカプセルの先頭に表示し、開くと修復ボタン（DNS キャッシュのクリア、使えるノードへの切り替え、プロキシアプリの再起動など）が出ます。
  復旧すると切断時間を表示します。ほかのソフトがシステムプロキシをオフにしたり変更したりしたときも通知し、ワンクリックで戻せます。
- **新しいアプリの通信**：アプリが初めてインターネットに接続したとき、アイランドにカードを出して「許可」または「通信をブロック」（Windows ファイアウォール規則。出口制御がオンならシステムプロキシ経由の通信も遮断）。
  初回は 10 分かけてよく使うアプリを学習し、更新でバージョン番号のフォルダーが変わっても同じアプリと認識します。
- **通知**：WeChat、Telegram、メールなどのメッセージや、Claude Code / Codex のタスク完了・承認待ちをアイランドで知らせます。
  カプセル右端のアイコン、カプセル内の 1 行、カード表示の 3 種類から選べ、通知ページではアプリごとにまとめます。
  既定では本文を表示せず、アプリと送信者のみ。おやすみモード、おやすみ時間帯、アプリ別ミュート、アプリ独自ポップアップの引き継ぎに対応。
- **アプリ別の接続**：アプリアイコン、プロセス数、リアルタイムの上り / 下り。プロキシ経由のアプリを先頭に表示し、各接続のローカルポート → ドメイン / IP、国、接続事業者、ノード、一致したルールを表示します。
- **出口制御**（Clash Party / Mihomo Party）：アプリ、ドメイン、メインドメイン、または「このアプリがこのドメインにアクセスするときだけ」の単位でプロキシ / 直結 / ブロックを選択。
  コアを再起動せずに即時反映され、「プロキシ」で使うノードはアイランドで切り替え・速度テストできます。
- **漏えい警告**：プロキシ経由のはずのサイトが直結になると警告（カプセルが赤くなり、システム通知）。先回りでブロックもできます：
  ルール漏れはプロキシを強制し、プロキシを迂回するアプリは Windows ファイアウォールでワンクリックで直結を禁止。
- **速度 / 通信量 / ノード**：リアルタイムの速度グラフ、アプリ別の「プロキシ / 直結」通信量（今日、7 日、30 日）、ノードの遅延と損失。
- **システムモニター**：CPU / GPU / メモリのアプリ別ランキング、プロセスの終了。スタートアップ アプリをタスク マネージャーと同じようにオン / オフ。
- **デスクトップウィンドウ**：普段はアイランドとトレイアイコンだけ。デスクトップウィンドウには概要（出口、速度、通信量、遅延、警告、AI 使用量、よく使うアプリ）とすべての設定があります。
- **見た目と使い心地**：リアルタイムのすりガラス（ライト / ダーク、システムに従う。明暗が混じった背景でも文字が読める）、配色プリセットとカスタムテーマ。
  カプセル / ノッチ / インジケーターバーの 3 つの形を画面のどの辺にもドッキング。マウスを置く / クリックで展開、クリック透過モード、カスタムショートカット、キーボード操作。
  全画面ゲームの邪魔をしません。なめらかなアニメーションは Windows のアニメーション設定に従います。
- **10 の表示言語**：简体中文、繁體中文、English、日本語、한국어、Русский、Español、Português (Brasil)、Français、Deutsch。既定では Windows の表示言語に従います。
- **クリップボード履歴**：コピーしたテキストと画像をアイランドの「クリップボード」ページに保存し、クリックでクリップボードに戻せます。検索・ピン留め・日数と件数での自動削除に対応し、パスワードマネージャーがプライベート指定した内容は記録しません。

> 見た目と操作は [fly-island](https://github.com/flyl1u/fly-island) を、一部の機能のアイデアは
> [BrimDeck](https://github.com/MoFeng2223/BrimDeck) を参考にしています。コードはすべて独自に書いています。

## インストール

[Releases](https://github.com/aileboeth/MicaBar/releases) からダウンロードします：

- `MicaBar_<バージョン>_x64-setup.exe`：インストーラー版。`C:\Program Files\MicaBar` にインストールされ、アプリ内で自動更新できます。
- `MicaBar_<バージョン>_portable.exe`：ポータブル版。単体の exe で、自動更新はありません。

Windows 10 2004 以降 / Windows 11（x64）と WebView2 ランタイムが必要です（Windows 11 は標準搭載、インストーラー版は自動でインストール）。
アプリ別の速度にカーネルの ETW イベントを使うため管理者権限で動作し、起動時に UAC が出ます。「Windows と一緒に起動」をオンにするとタスク スケジューラから起動するので出なくなります。

## 使い方

初回起動時、アイランド上で 30 秒ほどのチュートリアルが以下の操作を順に案内します。あとから 設定 → 情報 →「チュートリアルを再生」でもう一度見られます。

### 展開と折りたたみ

| 操作 | 結果 |
| --- | --- |
| カプセルにマウスを約 0.5 秒置く | パネルに展開（既定の「マウスを置く」方式。待ち時間は 設定 → 一般 → 操作 で変更） |
| マウスをパネルの外へ | 折りたたむ |
| カプセルをクリック / 外側をクリック | 「クリック」方式での展開 / 折りたたみ（設定 → 一般 → 操作 →「展開のしかた」で切り替え） |
| `Ctrl+Alt+N` | いつでも展開 / 折りたたみ（設定のショートカット欄をクリックして新しい組み合わせを押すと変更できます） |
| `Esc` | パネルを折りたたむ。下から出たシートやメニューが開いていれば先にそれを閉じます |

- 「マウスを置く」方式では、折りたたんだカプセルはクリックを妨げません。マウスを置いている間カプセルは透明になり、隠れたタブが見え、クリックは下のウィンドウに届きます。
- **クリック透過モード**：マウスはアイランドに一切触れず、ショートカットでのみ開けます。誤操作したくないときに。
- 全画面アプリ（ゲーム、動画）が前面にあるとき、カプセルは表示されたままですが自動では展開せず、クリックも妨げません。完全に隠す設定もできます。
- オプションの「ウィンドウ最大化時にインジケーターバーに縮小」：最大化したウィンドウが前面にある間、カプセルは細い線になり、ほかのウィンドウに切り替えると戻ります。

### ドラッグ、投げる、ドッキング

アイランドは画面の上・下・左・右のどの辺にも、その辺の始め・中央・終わりにも置けます。

1. **つかむ**：展開した状態でパネル上を**約 0.26 秒押したまま動かさない**とつかめます（時間は 設定 → 一般 → 操作 →「長押しでアイランドをつかむ時間」）。
   折りたたみ時は、**先に `Alt` を押しながら、カプセルを長押し**します（Alt を押している間はカプセルが透明にならないので、下のウィンドウではなくカプセルをつかめます）。
2. **辺に沿って投げる**：つかんだら左右にさっと振って離すと、その辺の始め・中央・終わりに滑って止まります。
3. **別の辺へ移す**：つかんだまま画面の中央へ引き出すとマウスについてきます。別の辺の近くで離すとそこにドッキングします。左右の辺ではカプセルが縦のノッチになります。

ドラッグしたくない場合は、設定 → 折りたたみ時の外観 でドッキング位置と辺の上での位置を直接選べます。

### サイズの調整

- トレイアイコンを右クリック →「アイランドのサイズを調整…」、デスクトップウィンドウ左下の「アイランドのサイズを調整」、または 設定 → 折りたたみ時の外観 / 展開時の外観 →「画面上でドラッグして調整」：
  画面上のカプセルとパネルにドラッグできる枠が出るので、端をドラッグして幅と高さを変え、終わったら「完了」をクリック（`Esc` でキャンセル）。
- 設定 → 折りたたみ時の外観 / 展開時の外観 のスライダーでも調整できます：カプセルの高さ、幅（0 = 内容に合わせて自動）、パネルの幅、最大の高さ、表示の拡大率。

### キーボード

パネル展開中：`Tab` / `Shift+Tab` で順にフォーカス移動。上部のページアイコンやネットワークページのタブにフォーカスがあるとき `←` / `→` で切り替え。
`↑` / `↓` でリストの行やボタン間を移動、`Enter` / `Space` で選択中のアプリを展開、`Esc` で折りたたみ。
設定の並べ替えできるリストは、選択して `Alt+↑` / `Alt+↓` でも順番を変えられます。

### パネルの各ページ

パネル上部のアイコンでページ（ネットワーク、システム、音楽、AI 使用量、通知）を切り替えます。表示するページと順番は 設定 → 展開時の外観 で変更でき、最後に開いたページを記憶します。

**ネットワーク**

- 一番上は**出口カード**です。左はプロキシ出口で、出口 IP ごとに 1 行、IP の後ろに種類タグ（家庭用 / 法人 / データセンター / モバイル / プロキシ判定）、
  2 行目にノードと所属。その IP を使うグループが IP の右側に並び、入りきらない分は「+N」にまとまります。クリックで全部表示、「折りたたむ」で戻します。
  右は直結出口（キャリア、アダプター、逆引き、前回の確認時刻）。IP やタグにマウスを置くと、登録組織、接続事業者、ASN、データの出典が見られます。
  右上の ↻ で出口を再確認、隣の脈拍アイコンで**ネットワーク診断**を開きます。
- カードの下の行は、プロキシアプリ、システムプロキシ、TUN、ローカルポート、コントローラーの状態です。
- タブ：**接続 / 待ち受け / 出口 / 警告 / 速度 / 通信量 / ノード**（入りきらないときはマウスホイールで左右にスクロール。順番は設定でドラッグして変更）。右の検索欄でアプリ、ドメイン、IP、ポートを絞り込みます。
  - **接続**：通信中のアプリごとに 1 行（プロキシ経由が先頭）。行をクリックすると各接続を展開。行の右の「出口」ボタンでアプリ全体のプロキシ / 直結 / ブロックを選び、
    接続の右の「⋯」ではその接続だけ（このドメイン、この IP、または「このアプリがアクセスするときだけ」）を指定します。選択中のボタンをもう一度押すとルールに戻ります。
  - **待ち受け**：この PC で待ち受けているポート。すべてのアダプターで待ち受けている（LAN からアクセス可能な）ものは印が付きます。
  - **出口**：出口制御のオン / オフ、出口ルールの確認と削除、「プロキシ」で使うノードの切り替えと速度テスト。
  - **警告**：プロキシの漏えいと新しいアプリの通信の記録。直結のブロック、ドメインの無視、通信の再開ができます。
  - **速度**：リアルタイムの速度グラフ。グラフ上でマウスを左右に動かすと 1 秒ごとに吸着し、上の大きな数字も変わります。グラフの下のアプリをクリックすると、
    そのアプリのグラフと統計のシートが下から出ます。シートは上下にドラッグでき、下に投げると閉じます。「接続を見る」「大きいグラフでこれだけ表示」があります。
  - **通信量**：アプリ別の「プロキシ / 直結」通信量を 今日 / 7 日 / 30 日 で切り替え。棒をクリックするとその日の内訳。
  - **ノード**：各出口ノードの遅延と損失。「今すぐテスト」ですぐに 1 回測定します。
- **ネットワーク診断**（脈拍アイコン、または切断時にカプセルの赤い表示をクリック）：アダプターからノードまで調べ、どこで切れているかを示し、下に修復ボタン
  （DNS キャッシュのクリア、システムプロキシの復元、プロキシアプリを開く / 再起動、使えるノードへの切り替えなど）を出します。

**システム**：CPU / GPU の各コアの使用率、メモリと VRAM。下では「使用量の多いアプリ」（CPU かメモリで並べ替え。✕ で確認後にプロセスを終了。Windows の中核プロセスと MicaBar 自身は終了しません）と
「スタートアップ アプリ」（タスク マネージャーの「スタートアップ アプリ」と同じスイッチ。オフにしても何も削除しません）を切り替えます。

**音楽**：再生中の曲（NetEase Cloud Music、QQ Music、Spotify、ブラウザの動画など）のジャケット、曲名、音楽に合わせて動く線、前へ / 再生・一時停止 / 次へ。

**AI 使用量**：AI ツールごとにカードがあり、各使用量枠の使用率とリセット時刻を表示。「今すぐ更新」ですぐに問い合わせます（公式 API のレート制限が厳しく、Claude は最短 10 分間隔）。

**通知**：アプリごとにまとめて表示。クリックで該当アプリを開き、「すべて既読」「すべて消去」。グループを**右クリック**するとそのアプリのミュートやグループの消去ができます。

### カプセルの表示

- カプセルに普段出す内容（出口 IP、速度、AI 使用量リング、時計、CPU / メモリ…）は 設定 → 折りたたみ時の外観 →「表示内容」でチェックとドラッグ並べ替え。
  幅に入りきらない項目は最後の 1 マスにまとまって順に表示されます。
- 切断、システムプロキシの変更、Claude Code の作業中・承認待ちのときは、カプセルの先頭に該当する表示が出て、クリックで診断を開いたり該当ターミナルへ切り替えたりできます。
- 出口 IP の変化、ノードの無応答や遅延増加、通信量の急増はカプセルに 5 秒間短く表示されます（設定 → ネットワーク →「短い通知」でオン / オフとしきい値）。
- 漏えいがあるとカプセルが赤くなり、未読通知があると右側にアプリアイコンと赤い点が出ます。

### デスクトップウィンドウ、設定、トレイ

- **トレイアイコンを左クリック**、またはパネル右上の**歯車**でデスクトップウィンドウを開きます：概要、接続、待ち受けポート、出口制御、漏えい警告、速度、通信量、ノード、システム、AI 使用量、通知、設定。
- **トレイアイコンを右クリック**：MicaBar を開く、設定、アイランドのサイズを調整、出口 IP を再確認、外観（システムに従う / ライトフロスト / ダークフロスト）、ログを開く、終了。
- 設定は左のサイドバーに分類されています（基本設定：一般、折りたたみ時の外観、展開時の外観、パネルのテーマ／ネットワーク／AI 使用状況／音楽／通知／情報）。どの機能もオフにできます。
  形とテーマはプレビューカードを見て選び、⠿ の付いたリストはドラッグで並べ替えます。一番下で設定をすべて既定に戻せます。
- **表示言語**：設定 → 一般 →「言語」。既定の「システムに従う」は Windows の表示言語を使います。変更するとすべてのウィンドウが再読み込みされ、トレイメニューも切り替わります。

## グループ別の出口

出口制御を有効にすると、上書きがプロキシグループごとにこの PC だけで待ち受けるポート（`127.0.0.1:47800` から）を開き、そこに入った通信はそのグループに直接渡されます。
MicaBar は各ポートから出口 IP を確認するので、「既定」「AI」「YouTube」がそれぞれどこから出ているかが分かります。
既定ではフォールバックグループ + 最近通信のあったグループ（最大 4 つ）を表示し、設定で手動選択もできます。

## 出口制御

Clash Party / Mihomo Party を初めて検出すると、アイランドで有効化を提案します。有効にすると Clash Party の上書き一覧をバックアップし、
グローバル上書き「MicaBar 出口控制」を追加して Clash Party を一度再起動します（約 3 秒切断）。読み込みに失敗した場合は自動で元に戻します。
あとはアプリ行の「出口」や接続の「⋯」から選ぶだけです。より具体的なルールが優先されるので、「アプリ全体を直結」と「このアプリの *.example.com だけプロキシ」は同時に機能します。
上書きは「出口」タブの下部から無効化・削除できます。

システムプロキシモードではシステムプロキシに従うアプリしか制御できません。すべてのアプリを対象にするには TUN を有効にしてください。

## 対応プロキシアプリ

| プロキシアプリ | プロキシ出口 / ローカルポート | ノード、グループ、一致したルール | 出口制御 / 先回りブロック |
|---|---|---|---|
| Clash Party / Mihomo Party | ✓ | ✓ | ✓ |
| Clash Verge Rev | ✓ | ✓（コントローラー経由） | — |
| v2rayN、Throne（NekoRay）、Hiddify、FlClash、Karing | ✓（システムプロキシのポート、またはよく使うローカルポート） | — | — |

システムプロキシ、TUN アダプター、アプリ別の接続はプロキシアプリに関係なく表示されます。

## 通知

通知は 3 つの経路から、すべてこの PC 上で読み取ります：

- **タスクバーの点滅**：WeChat 4.x はメッセージが来てもタスクバーを点滅させるだけで、システム通知もウィンドウの内容も読めないため、「WeChat · 新着 N 件」としか表示できません。クリックで WeChat を開きます。ほかの点滅するアプリも同様です。
- **アプリ独自のポップアップ / システム通知**：システム通知をオフにした Telegram は右下に独自の小窓を出します。MicaBar はそれを見つけるとメインウィンドウのチャット一覧を一度読み取り（Windows UI オートメーション）、新着数が増えた会話を探します。
  Windows 通知を使うアプリはシステムの通知データベースから読みます。「ポップアップを引き継ぐ」をオンにすると、アプリ（または Windows）自身のポップアップは出ず、アイランドだけで知らせます。
- Windows 通知を使うアプリ（WhatsApp、Teams、Slack、Discord、Signal、Zoom、LINE など）はそれぞれの名前とアイコンで表示されます。同じメッセージがタスクバー点滅と通知の両方で来ても 1 件として数えます。
- 通知を出したアプリを開くと既読になり、赤い点が消えます。そのアプリを使っている最中に届いた通知は知らせません。
- **AI 完了通知**：設定 → 通知 で「接続する」を押すと、Claude Code の `~/.claude/settings.json` または Codex の `~/.codex/config.toml` にフックを追加します（変更前に自動バックアップ、ワンクリックで削除可）。
  タスク完了や承認待ちのとき、`curl` でこの PC の `127.0.0.1:47900` に知らせます（ランダムなトークン付き）。

## クリップボード履歴

- コピーしたテキストと画像（スクリーンショットなど）がパネルの「クリップボード」ページに時刻順に並び、ピン留めは先頭に表示されます。同じ内容をもう一度コピーすると先頭に移るだけで、重複しません。
- 項目をクリックするとクリップボードに戻すだけで、貼り付けは自分で Ctrl+V します。項目にカーソルを置くと右上でピン留め・削除、上部で検索できます。
- 設定 → クリップボード で、画像も記録するか、この PC のディスクに保存するか（現在の Windows アカウントの鍵で暗号化、再起動後も残る）メモリのみにするか、何日・何件まで残すかを選べます。ピン留めは自動で削除されません。
- Bitwarden、KeePass、1Password などのパスワードマネージャーはパスワードのコピー時に「記録しない」印を付けます。その内容は既定でスキップします。
- カプセルの右端にクリップボードアイコンがあり、新しくコピーすると跳ねます（設定 → 折りたたみ時の外観 でオフにできます）。

## 漏えい警告

「プロキシ必須」ルールリスト = 組み込みの主要サービス一覧（約 140 のメインドメイン）+ 購読する gfw リスト（毎日更新）+ 独自の追加 / インポート（ドメインのみ、v2fly、Clash ルール形式に対応）。漏えいは 2 種類です：

- **ルール漏れ**：プロキシアプリは通ったものの、振り分けルールで直結と判定されたもの。「先回りでブロック」をオンにすると、こうしたドメインは直結ルールに当たる前にプロキシへ回されます。サブスクリプションのサービス別グループには影響しません。
- **プロキシ迂回**：アプリがプロキシアプリを通らずに直接接続したもの（システムプロキシを使わない、または TUN 確立前の接続）。警告カードからワンクリックで
  「{アプリ} の直結をブロック」できます（Windows ファイアウォール規則。インターネット側のアドレスだけを止め、ローカルのプロキシポート経由の通信はそのまま）。いつでも解除できます。

## プライバシー：MicaBar が接続する先

統計（接続、通信量、ルール、警告の記録）はすべてこの PC の `%LOCALAPPDATA%\MicaBar\` にだけ保存されます。MicaBar 自身が行う通信は次のものだけです：

| 用途 | 接続先 | タイミング |
| --- | --- | --- |
| プロキシ出口 IP | ipinfo.io → api.ipify.org → ifconfig.me（ローカルのプロキシポート経由。グループ別の出口は各グループのループバックポート経由） | 起動時、ネットワーク / プロキシの変化時、5 分ごと |
| 直結出口 IP | 4.ipw.cn → myip.ipip.net → ip.3322.net（物理アダプターにバインド。名前解決は 223.5.5.5 / 119.29.29.29） | 同上 |
| IP の種類と所属 | proxycheck.io（HTTPS）と ip-api.com（無料版は HTTP のみ）に各出口 IP（直結出口も含む）を問い合わせます。プロキシアプリのローカルポート経由 | 新しい出口 IP が現れたとき。IP ごとに 24 時間キャッシュ。設定 → ネットワーク でオフにできます |
| ノード遅延 | mihomo コアが `www.gstatic.com/generate_204` で測定 | 15～60 秒ごと（リソースプロファイル） |
| gfw リスト | cdn.jsdelivr.net / raw.githubusercontent.com（Loyalsoldier/v2ray-rules-dat） | 有効時に 1 日 1 回 |
| 更新の確認 | github.com/aileboeth/MicaBar の latest.json | 有効時に 1 日 1 回 |
| AI 使用量 | api.anthropic.com（Claude Code）、chatgpt.com（Codex）、cli-chat-proxy.grok.com（Grok）、ローカルの Antigravity 言語サーバー | 有効時に 10 分ごと（変更可）。常にプロキシアプリのローカルポート経由で、直結は絶対にしません（ポートがなければ問い合わせません） |
| 切断の診断 | 直結：119.29.29.29 / 223.5.5.5 の HTTP 名前解決 API（qq.com を照会）。プロキシ経由：`www.gstatic.com/generate_204`。DNS：システム DNS で www.baidu.com を解決（キャッシュなし）。診断時はルーターに ping | 有効時、直結は 10 秒ごと、プロキシ経由と DNS は 30 秒ごとに 1 回。失敗したときだけ完全な診断 |

国 / ASN はプロキシアプリ付属のオフラインデータベース（`country.mmdb`、`ASN.mmdb`）を使い、接続先の IP をどこにも送りません。
AI 使用量は各ツールがこの PC に保存しているサインイン情報を使い、そのツール自身のサービスにだけ送ります。保存、ログへの記録、更新はしません。
再生中の曲は Windows のメディアコントロールから読み、通信はしません。
通知も通信しません。その日の通知はメモリ上にだけ置き、本文はディスクにもログにも書かず、既定ではアイランドにも表示しません。ローカルポート `127.0.0.1:47900` はトークン付きの AI フックの呼び出しだけを受け付けます。
mihomo コントローラーのシークレットは実行時に設定ファイルから読むだけで、保存も外部送信もしません。

クリップボード履歴はネットに接続しません。記録はこの PC（`%LOCALAPPDATA%\MicaBar\clipboard`、暗号化）かメモリだけにあり、ログにも書きません。

## ソースからのビルド

Rust（rustup）、Visual Studio C++ Build Tools、Node.js + pnpm が必要です。

```powershell
pnpm install
pnpm build            # 単体の exe：src-tauri\target\release\micabar.exe
pnpm release          # インストーラー + ポータブル版 + 更新マニフェスト -> dist\release-<バージョン>\（更新用の署名鍵 keys\micabar.key が必要）
```

構成：`src-tauri\src\`（Rust バックエンド：ソケットテーブル、ETW、mihomo コントローラー、出口確認、漏えいガード、ウィンドウ制御、すりガラスのキャプチャ…）、
`ui\`（バンドル不要の素の HTML / CSS / JS。`ui\i18n\` が各言語の翻訳で、コード中の中国語原文がキー）、`tools\`（リリーススクリプト、テスト用 VM ドライバー）。
実装メモ（中国語）：[docs/internals.zh-CN.md](docs/internals.zh-CN.md)。
