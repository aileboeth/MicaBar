# MicaBar

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **한국어** · [Русский](README.ru.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

Windows용 "다이내믹 아일랜드" 스타일 네트워크 모니터입니다. 화면 위쪽의 반투명 유리 캡슐이 평소에는 출구 IP와 연결 수를 보여 주고,
마우스를 올리면 펼쳐져서 어떤 앱이 어떤 포트를 쓰고 어디로 연결하며 어느 프록시 노드를 거치는지 보여 줍니다.
그 자리에서 프록시로 보낼지 직접 연결할지도 정할 수 있습니다.

## 기능

- **그룹별 출구**: 구독의 각 그룹(기본 프록시, AI, 스트리밍…)의 출구 IP와 사용 노드, 그리고 직접 연결 출구.
  국가, 접속 사업자 / ASN과 함께 IP 유형(가정용 / 기업용 / 데이터센터 / 모바일, 프록시로 등록된 IP는 따로 표시)과 소속(중국 본토 IP는 통신사와 성)도 보여 줍니다.
- **캡슐 순환 표시**: 그룹별 출구, 재생 중인 곡(표지 + 곡명), AI 사용량, 속도, 노드 지연이 차례로 바뀝니다. 내용과 간격은 설정할 수 있습니다.
- **AI 사용량**: Claude Code, Codex, Antigravity, Grok의 구독 사용량(5시간 / 매주 등)과 초기화 시각. 링 가운데에 각 도구의 아이콘.
- **실행 중인 AI 작업**: Claude Code가 일하는 동안 캡슐 맨 앞에 프로젝트 이름과 경과 시간을 보여 주고, 승인을 기다리면 주황색으로 바뀝니다.
  펼친 아일랜드 위쪽에도 나타나며, 클릭하면 해당 터미널로 전환합니다. Esc로 중단하거나 터미널을 닫으면 사라집니다.
- **끊김 진단**: 백그라운드에서 10초마다 가볍게 확인하고, 두 번 연속 실패하면 어댑터 → 라우터 → DNS → 인터넷 → 프록시 앱 → 노드 순서로 확인합니다.
  어느 구간이 끊겼는지("DNS 고장", "노드 중단", "회선 끊김"…) 캡슐 맨 앞에 표시하고, 열면 수리 버튼(DNS 캐시 비우기, 쓸 수 있는 노드로 바꾸기, 프록시 앱 다시 시작 등)이 있습니다.
  복구되면 얼마나 끊겼는지 알려 줍니다. 다른 프로그램이 시스템 프록시를 끄거나 바꿔도 알려 주고 한 번에 복원할 수 있습니다.
- **새 앱의 인터넷 접속**: 앱이 처음 인터넷에 연결되면 아일랜드에 카드를 띄워 "허용" 또는 "인터넷 차단"(Windows 방화벽 규칙, 출구 제어가 켜져 있으면 시스템 프록시를 거치는 트래픽도 차단).
  처음에는 10분 동안 자주 쓰는 앱을 익히고, 업데이트로 버전 폴더가 바뀌어도 같은 앱으로 알아봅니다.
- **알림**: WeChat, Telegram, 메일 등의 메시지와 Claude Code / Codex의 작업 완료·승인 대기를 아일랜드에서 알립니다.
  캡슐 오른쪽 끝의 앱 아이콘, 캡슐 안의 한 줄, 카드 중 선택할 수 있고 알림 페이지에서 앱별로 묶어 보여 줍니다.
  기본값은 내용 숨김(앱과 보낸 사람만). 방해 금지, 방해 금지 시간, 앱별 음소거, 앱 자체 팝업 가져오기를 지원합니다.
- **앱별 연결**: 앱 아이콘, 프로세스 수, 실시간 업로드 / 다운로드. 프록시를 거치는 앱을 앞에 두고, 연결마다 로컬 포트 → 도메인 / IP, 국가, 접속 사업자, 노드, 일치한 규칙을 보여 줍니다.
- **출구 제어**(Clash Party / Mihomo Party): 앱, 도메인, 주 도메인, 또는 "이 앱이 이 도메인에 접속할 때만" 단위로 프록시 / 직접 연결 / 차단을 고릅니다.
  코어를 다시 시작하지 않고 바로 적용되며, "프록시"에 쓰는 노드는 아일랜드에서 바꾸고 속도를 측정할 수 있습니다.
- **누출 경고**: 프록시를 거쳐야 할 사이트가 직접 연결되면 경고합니다(캡슐이 빨개지고 시스템 알림). 미리 차단할 수도 있습니다:
  규칙 누락은 프록시를 강제하고, 프록시를 우회하는 앱은 Windows 방화벽으로 한 번에 직접 연결을 막습니다.
- **속도 / 트래픽 / 노드**: 실시간 속도 그래프, 앱별 "프록시 / 직접 연결" 트래픽(오늘, 7일, 30일), 노드 지연과 손실.
- **시스템 모니터**: CPU / GPU / 메모리 앱별 순위, 프로세스 종료. 시작 앱을 작업 관리자처럼 켜고 끄기.
- **데스크톱 창**: 평소에는 아일랜드와 트레이 아이콘만 있습니다. 데스크톱 창에는 개요(출구, 속도, 트래픽, 지연, 경고, AI 사용량, 활발한 앱)와 모든 설정이 있습니다.
- **보기 좋고 쓰기 편하게**: 실시간 반투명 유리(라이트 / 다크, 시스템 따르기, 밝고 어두운 부분이 섞인 배경에서도 글자가 잘 보임), 색 프리셋과 사용자 테마.
  캡슐 / 노치 / 표시줄 세 가지 모양을 화면 어느 가장자리에나 도킹. 마우스 올리기 / 클릭으로 펼치기, 클릭 통과 모드, 사용자 단축키, 키보드 조작.
  전체 화면 게임을 방해하지 않습니다. 부드러운 애니메이션은 Windows 애니메이션 설정을 따릅니다.
- **10가지 인터페이스 언어**: 简体中文, 繁體中文, English, 日本語, 한국어, Русский, Español, Português (Brasil), Français, Deutsch. 기본값은 Windows 표시 언어를 따릅니다.
- **클립보드 기록**: 복사한 텍스트와 그림을 아일랜드의 「클립보드」 페이지에 모아 두고, 클릭하면 클립보드로 다시 복사합니다. 검색·고정, 날짜와 개수에 따른 자동 정리를 지원하며, 비밀번호 관리자가 비공개로 표시한 내용은 기록하지 않습니다.

> 모양과 상호 작용은 [fly-island](https://github.com/flyl1u/fly-island)를, 일부 기능 아이디어는
> [BrimDeck](https://github.com/MoFeng2223/BrimDeck)을 참고했습니다. 코드는 모두 독자적으로 작성했습니다.

## 설치

[Releases](https://github.com/aileboeth/MicaBar/releases)에서 내려받으세요:

- `MicaBar_<버전>_x64-setup.exe`: 설치 버전. `C:\Program Files\MicaBar`에 설치되며 앱 안에서 자동 업데이트됩니다.
- `MicaBar_<버전>_portable.exe`: 포터블 버전. exe 하나이며 자동 업데이트는 없습니다.

Windows 10 2004 이상 / Windows 11(x64)과 WebView2 런타임이 필요합니다(Windows 11에는 기본 포함, 설치 버전은 자동 설치).
앱별 속도에 커널 ETW 이벤트를 쓰기 때문에 관리자 권한으로 실행되며 시작할 때 UAC가 뜹니다. "Windows와 함께 시작"을 켜면 작업 스케줄러로 시작해 더 이상 뜨지 않습니다.

## 사용법

처음 시작하면 아일랜드에서 30초 정도의 튜토리얼이 아래 조작을 차례로 보여 줍니다. 나중에 설정 → 정보 → "튜토리얼 다시 보기"로 다시 볼 수 있습니다.

### 펼치기와 접기

| 조작 | 결과 |
| --- | --- |
| 캡슐에 마우스를 약 0.5초 올려 두기 | 패널로 펼쳐짐(기본 "마우스 올리기" 방식, 대기 시간은 설정 → 일반 → 조작에서 변경) |
| 마우스를 패널 밖으로 | 접힘 |
| 캡슐 클릭 / 바깥 클릭 | "클릭" 방식에서 펼치기 / 접기(설정 → 일반 → 조작 → "펼치는 방법"에서 전환) |
| `Ctrl+Alt+N` | 언제든 펼치기 / 접기(설정의 단축키 칸을 클릭하고 새 조합을 누르면 바뀝니다) |
| `Esc` | 패널을 접기. 아래에서 올라온 시트나 메뉴가 열려 있으면 그것부터 닫습니다 |

- "마우스 올리기" 방식에서 접힌 캡슐은 클릭을 막지 않습니다. 마우스를 올려 두면 캡슐이 투명해져 가려진 탭이 보이고, 클릭은 아래 창으로 갑니다.
- **클릭 통과 모드**: 마우스가 아일랜드에 전혀 닿지 않고 단축키로만 열 수 있습니다. 실수로 건드리고 싶지 않을 때 좋습니다.
- 전체 화면 앱(게임, 동영상)이 앞에 있으면 캡슐은 계속 보이지만 자동으로 펼쳐지지 않고 클릭도 막지 않습니다. 완전히 숨기도록 설정할 수도 있습니다.
- 선택 사항 "창이 최대화되면 표시줄로 줄이기": 최대화된 창이 앞에 있는 동안 캡슐이 가는 선이 되고, 다른 창으로 바꾸면 돌아옵니다.

### 끌기, 던지기, 도킹

아일랜드는 화면의 위·아래·왼쪽·오른쪽 어느 가장자리에나, 그 가장자리의 시작·가운데·끝에 둘 수 있습니다.

1. **잡기**: 펼친 상태에서 패널을 **약 0.26초 동안 움직이지 않고 누르고 있으면** 잡힙니다(시간은 설정 → 일반 → 조작 → "아일랜드를 잡는 길게 누르기 시간").
   접혀 있을 때는 **먼저 `Alt`를 누른 채 캡슐을 길게 누릅니다**(Alt를 누르는 동안에는 캡슐이 투명해지지 않아서 아래 창이 아닌 캡슐을 잡습니다).
2. **가장자리를 따라 던지기**: 잡은 뒤 왼쪽이나 오른쪽으로 휙 던지고 놓으면 그 가장자리의 시작·가운데·끝으로 미끄러져 멈춥니다.
3. **다른 가장자리로 옮기기**: 잡은 채 화면 가운데로 끌어내면 마우스를 따라옵니다. 다른 가장자리 근처에서 놓으면 그곳에 도킹합니다. 왼쪽 / 오른쪽 가장자리에서는 캡슐이 세로 노치가 됩니다.

끌기 싫다면 설정 → 접힌 모양에서 도킹 위치와 가장자리에서의 위치를 바로 고를 수 있습니다.

### 크기 조정

- 트레이 아이콘 오른쪽 클릭 → "아일랜드 크기 조정…", 데스크톱 창 왼쪽 아래의 "아일랜드 크기 조정", 또는 설정 → 접힌 모양 / 펼친 모양 → "화면에서 드래그하여 조정":
  화면의 캡슐과 패널에 끌 수 있는 테두리가 생깁니다. 가장자리를 끌어 폭과 높이를 바꾸고 다 되면 "완료"를 누르세요(`Esc`로 취소).
- 설정 → 접힌 모양 / 펼친 모양의 슬라이더로도 조정할 수 있습니다: 캡슐 높이, 폭(0 = 내용에 맞춰 자동), 패널 폭, 최대 높이, 인터페이스 배율.

### 키보드

패널이 펼쳐져 있을 때: `Tab` / `Shift+Tab`으로 차례로 포커스 이동. 위쪽 페이지 아이콘이나 네트워크 페이지 탭에 포커스가 있으면 `←` / `→`로 전환.
`↑` / `↓`로 목록의 행과 버튼 사이를 이동, `Enter` / `Space`로 현재 앱 펼치기, `Esc`로 접기.
설정에서 순서를 바꿀 수 있는 목록은 항목을 선택하고 `Alt+↑` / `Alt+↓`로도 옮길 수 있습니다.

### 패널의 페이지

패널 위쪽 아이콘으로 페이지(네트워크, 시스템, 음악, AI 사용량, 알림)를 전환합니다. 표시할 페이지와 순서는 설정 → 펼친 모양에서 바꾸며, 마지막에 본 페이지를 기억합니다.

**네트워크**

- 맨 위는 **출구 카드**입니다. 왼쪽은 프록시 출구로, 출구 IP마다 한 줄이고 IP 뒤에 유형 태그(가정용 / 기업용 / 데이터센터 / 모바일 / 프록시 표시),
  둘째 줄에 노드와 소속이 있습니다. 그 IP를 쓰는 그룹들이 IP 오른쪽에 놓이고, 다 들어가지 않으면 "+N"으로 접힙니다. 클릭하면 모두 보이고 "접기"로 다시 접습니다.
  오른쪽은 직접 연결 출구(통신사, 어댑터, 역방향 DNS, 마지막 확인 시각). IP나 태그에 마우스를 올리면 등록 조직, 접속 사업자, ASN, 데이터 출처가 보입니다.
  오른쪽 위 ↻는 출구를 다시 확인하고, 옆의 맥박 아이콘은 **네트워크 진단**을 엽니다.
- 카드 아래 줄은 프록시 앱, 시스템 프록시, TUN, 로컬 포트, 컨트롤러의 상태입니다.
- 탭: **연결 / 수신 / 출구 / 경고 / 속도 / 트래픽 / 노드**(다 들어가지 않으면 마우스 휠로 좌우 스크롤, 순서는 설정에서 끌어서 변경). 오른쪽 검색 칸은 앱, 도메인, IP, 포트로 거릅니다.
  - **연결**: 인터넷을 쓰는 앱마다 한 줄(프록시 경유가 앞). 줄을 클릭하면 연결이 펼쳐집니다. 줄 오른쪽 "출구" 버튼으로 앱 전체의 프록시 / 직접 연결 / 차단을 고르고,
    연결 오른쪽 "⋯"은 그 연결만(이 도메인, 이 IP, 또는 "이 앱이 접속할 때만") 정합니다. 선택된 버튼을 한 번 더 누르면 규칙대로 돌아갑니다.
  - **수신**: 이 PC에서 수신 중인 포트. 모든 어댑터에서 수신하는(LAN에서 접근 가능한) 포트는 표시됩니다.
  - **출구**: 출구 제어 켜기 / 끄기, 출구 규칙 보기와 삭제, "프록시"에 쓰는 노드 바꾸기와 속도 측정.
  - **경고**: 프록시 누출과 새 앱의 인터넷 접속 기록. 직접 연결 차단, 도메인 무시, 인터넷 다시 허용.
  - **속도**: 실시간 속도 그래프. 그래프 위에서 마우스를 좌우로 움직이면 초마다 맞춰지고 위쪽 큰 숫자도 바뀝니다. 그래프 아래 앱을 클릭하면
    그 앱의 그래프와 통계 시트가 아래에서 올라옵니다. 시트는 위아래로 끌 수 있고 아래로 던지면 닫힙니다. "연결 보기", "큰 그래프에서 이것만 보기"가 있습니다.
  - **트래픽**: 앱별 "프록시 / 직접 연결" 트래픽을 오늘 / 7일 / 30일로 전환. 막대를 클릭하면 그날의 내역.
  - **노드**: 출구 노드별 지연과 손실. "지금 측정"으로 바로 한 번 측정합니다.
- **네트워크 진단**(맥박 아이콘, 또는 끊겼을 때 캡슐의 빨간 표시 클릭): 어댑터부터 노드까지 확인해 어디서 끊겼는지 알려 주고, 아래에 수리 버튼
  (DNS 캐시 비우기, 시스템 프록시 복원, 프록시 앱 열기 / 다시 시작, 쓸 수 있는 노드로 바꾸기 등)을 보여 줍니다.

**시스템**: CPU / GPU 코어별 사용률, 메모리와 VRAM. 아래에서 "사용량이 많은 앱"(CPU나 메모리로 정렬, ✕를 누르면 확인 후 프로세스 종료, Windows 핵심 프로세스와 MicaBar 자체는 종료하지 않음)과
"시작 앱"(작업 관리자의 "시작 앱"과 같은 스위치, 꺼도 아무것도 지우지 않음)을 전환합니다.

**음악**: 재생 중인 곡(NetEase Cloud Music, QQ Music, Spotify, 브라우저 동영상 등)의 표지, 곡명, 음악에 맞춰 움직이는 선, 이전 / 재생·일시정지 / 다음.

**AI 사용량**: AI 도구마다 카드 하나로 각 한도 구간의 사용률과 초기화 시각을 보여 줍니다. "지금 새로 고침"으로 바로 조회합니다(공식 API의 속도 제한이 엄격해 Claude는 최소 10분 간격).

**알림**: 앱별로 묶어 표시합니다. 클릭하면 해당 앱을 열고, "모두 읽음", "모두 지우기". 그룹을 **오른쪽 클릭**하면 그 앱을 음소거하거나 그룹을 지울 수 있습니다.

### 캡슐이 알려 주는 것

- 캡슐에 평소 보이는 내용(출구 IP, 속도, AI 사용량 링, 시계, CPU / 메모리…)은 설정 → 접힌 모양 → "표시 내용"에서 선택하고 끌어서 순서를 바꿉니다.
  폭에 다 들어가지 않는 항목은 마지막 칸에 모여 돌아가며 표시됩니다.
- 끊김, 시스템 프록시 변경, Claude Code가 일하거나 승인을 기다릴 때는 캡슐 맨 앞에 해당 표시가 나타나고, 클릭하면 진단을 열거나 해당 터미널로 전환합니다.
- 출구 IP 변경, 노드 무응답이나 지연 증가, 트래픽 급증은 캡슐에 5초 동안 짧게 표시됩니다(설정 → 네트워크 → "짧은 알림"에서 켜고 끄기와 기준값).
- 누출이 있으면 캡슐이 빨개지고, 읽지 않은 알림이 있으면 오른쪽에 앱 아이콘과 빨간 점이 나타납니다.

### 데스크톱 창, 설정, 트레이

- **트레이 아이콘 왼쪽 클릭** 또는 패널 오른쪽 위 **톱니바퀴**로 데스크톱 창을 엽니다: 개요, 연결, 수신 포트, 출구 제어, 누출 경고, 속도, 트래픽, 노드, 시스템, AI 사용량, 알림, 설정.
- **트레이 아이콘 오른쪽 클릭**: MicaBar 열기, 설정, 아일랜드 크기 조정, 출구 IP 다시 확인, 모양(시스템 따르기 / 라이트 프로스트 / 다크 프로스트), 로그 열기, 종료.
- 설정은 왼쪽 사이드바에 분류되어 있습니다(기본 설정: 일반, 접힌 모양, 펼친 모양, 패널 테마 / 네트워크 / AI 사용 / 음악 / 알림 / 정보). 모든 기능을 끌 수 있습니다.
  모양과 테마는 미리 보기 카드를 보고 고르고, ⠿가 있는 목록은 끌어서 순서를 바꿉니다. 맨 아래에서 모든 설정을 기본값으로 되돌릴 수 있습니다.
- **인터페이스 언어**: 설정 → 일반 → "언어". 기본값 "시스템 따르기"는 Windows 표시 언어를 씁니다. 바꾸면 모든 창이 새로 고쳐지고 트레이 메뉴도 바뀝니다.

## 그룹별 출구

출구 제어를 켜면 오버라이드가 프록시 그룹마다 이 PC에서만 듣는 포트(`127.0.0.1:47800`부터)를 열고, 그 포트로 들어온 트래픽은 해당 그룹으로 바로 넘어갑니다.
MicaBar는 각 포트로 출구 IP를 확인하므로 "기본", "AI", "YouTube"가 각각 어디로 나가는지 알 수 있습니다.
기본값은 대체 그룹 + 최근 트래픽이 있던 그룹(최대 4개)이며, 설정에서 직접 고를 수도 있습니다.

## 출구 제어

Clash Party / Mihomo Party를 처음 감지하면 아일랜드에서 켜기를 제안합니다. 켜면 Clash Party의 오버라이드 목록을 백업하고
전역 오버라이드 "MicaBar 出口控制"를 추가한 뒤 Clash Party를 한 번 다시 시작합니다(약 3초 끊김). 불러오기에 실패하면 자동으로 되돌립니다.
그다음에는 앱 줄의 "출구"나 연결의 "⋯"에서 고르면 됩니다. 더 구체적인 규칙이 우선하므로 "앱 전체 직접 연결"과 "이 앱의 *.example.com만 프록시"가 함께 적용됩니다.
"출구" 탭 아래쪽에서 끄고 오버라이드를 제거할 수 있습니다.

시스템 프록시 모드에서는 시스템 프록시를 따르는 앱만 제어할 수 있습니다. 모든 앱을 다루려면 TUN을 켜세요.

## 알림

알림은 세 곳에서 오며, 모두 이 PC에서 읽습니다:

- **작업 표시줄 깜박임**: WeChat 4.x는 메시지가 와도 작업 표시줄만 깜박이고 시스템 알림도 없고 창 내용도 읽을 수 없어서 "WeChat · 새 메시지 N개"만 표시할 수 있습니다. 클릭하면 WeChat이 열립니다. 다른 깜박이는 앱도 같습니다.
- **앱 자체 팝업 / 시스템 알림**: 시스템 알림을 끈 Telegram은 오른쪽 아래에 자체 작은 창을 띄웁니다. MicaBar는 그 창을 보면 주 창의 채팅 목록을 한 번 읽어(Windows UI 자동화) 새 메시지 수가 늘어난 대화를 찾습니다.
  Windows 알림을 쓰는 앱은 시스템 알림 데이터베이스에서 읽습니다. "팝업 가져오기"를 켜면 앱(또는 Windows) 자체 팝업은 나타나지 않고 아일랜드에서만 알립니다.
- Windows 알림을 쓰는 앱(WhatsApp, Teams, Slack, Discord, Signal, Zoom, LINE 등)은 각자의 이름과 아이콘으로 표시됩니다. 같은 메시지가 작업 표시줄 깜박임과 알림으로 동시에 와도 하나로 셉니다.
- 알림을 보낸 앱을 열면 읽은 것으로 처리되어 빨간 점이 사라집니다. 그 앱을 쓰는 중에 온 알림은 알리지 않습니다.
- **AI 완료 알림**: 설정 → 알림에서 "연결"을 누르면 Claude Code의 `~/.claude/settings.json` 또는 Codex의 `~/.codex/config.toml`에 훅을 추가합니다(수정 전 자동 백업, 한 번에 제거 가능).
  작업이 끝나거나 승인을 기다리면 `curl`로 이 PC의 `127.0.0.1:47900`에 알립니다(임의 토큰 포함).

## 클립보드 기록

- 복사한 텍스트와 그림(스크린샷 등)이 패널의 「클립보드」 페이지에 시간순으로 쌓이고, 고정한 항목은 맨 위에 있습니다. 같은 내용을 다시 복사하면 맨 위로 옮겨질 뿐 중복되지 않습니다.
- 항목을 클릭하면 클립보드로 다시 복사만 하고, 붙여넣기는 직접 Ctrl+V로 합니다. 항목에 마우스를 올리면 오른쪽 위에서 고정·삭제, 위쪽에서 검색할 수 있습니다.
- 설정 → 클립보드에서 그림도 기록할지, 이 PC 디스크에 저장할지(현재 Windows 계정의 키로 암호화, 다시 시작해도 남음) 메모리에만 둘지, 며칠·몇 개까지 보관할지 고를 수 있습니다. 고정한 항목은 자동으로 삭제되지 않습니다.
- Bitwarden, KeePass, 1Password 같은 비밀번호 관리자는 비밀번호를 복사할 때 「기록하지 말 것」 표시를 붙입니다. 이런 내용은 기본으로 건너뜁니다.
- 캡슐 오른쪽 끝의 클립보드 아이콘이 새로 복사할 때 튑니다(설정 → 접힌 모양에서 끌 수 있음).

## 누출 경고

"프록시 필수" 규칙 목록 = 내장 주요 서비스 목록(주 도메인 약 140개) + 구독하는 gfw 목록(매일 업데이트) + 사용자 추가 / 가져오기(도메인만, v2fly, Clash 규칙 형식 지원). 누출은 두 가지입니다:

- **규칙 누락**: 프록시 앱은 거쳤지만 분류 규칙이 직접 연결로 판정한 경우. "미리 차단"을 켜면 이런 도메인은 직접 연결 규칙에 닿기 전에 프록시로 보내집니다. 구독의 서비스별 그룹은 영향을 받지 않습니다.
- **프록시 우회**: 앱이 프록시 앱을 거치지 않고 바로 연결한 경우(시스템 프록시를 쓰지 않거나 TUN 이전의 연결). 경고 카드에서 한 번에
  "{앱}의 직접 연결 차단"을 할 수 있습니다(Windows 방화벽 규칙, 인터넷 주소만 막고 로컬 프록시 포트로는 계속 연결 가능). 언제든 해제할 수 있습니다.

## 개인 정보: MicaBar가 연결하는 곳

모든 통계(연결, 트래픽, 규칙, 경고 기록)는 이 PC의 `%LOCALAPPDATA%\MicaBar\`에만 저장됩니다. MicaBar가 직접 보내는 요청은 다음뿐입니다:

| 용도 | 주소 | 시점 |
| --- | --- | --- |
| 프록시 출구 IP | ipinfo.io → api.ipify.org → ifconfig.me(로컬 프록시 포트 경유, 그룹별 출구는 각 그룹의 루프백 포트 경유) | 시작, 네트워크 / 프록시 변경, 5분마다 |
| 직접 연결 출구 IP | 4.ipw.cn → myip.ipip.net → ip.3322.net(물리 어댑터에 바인딩, 도메인은 223.5.5.5 / 119.29.29.29로 조회) | 위와 같음 |
| IP 유형과 소속 | proxycheck.io(HTTPS)와 ip-api.com(무료 버전은 HTTP만)에 각 출구 IP(직접 연결 출구 포함)를 조회. 프록시 앱의 로컬 포트 경유 | 새 출구 IP가 나타날 때. IP마다 24시간 캐시. 설정 → 네트워크에서 끌 수 있음 |
| 노드 지연 | mihomo 코어가 `www.gstatic.com/generate_204`로 측정 | 15~60초마다(리소스 프로필) |
| gfw 목록 | cdn.jsdelivr.net / raw.githubusercontent.com(Loyalsoldier/v2ray-rules-dat) | 켜져 있을 때 하루 한 번 |
| 업데이트 확인 | github.com/aileboeth/MicaBar의 latest.json | 켜져 있을 때 하루 한 번 |
| AI 사용량 | api.anthropic.com(Claude Code), chatgpt.com(Codex), cli-chat-proxy.grok.com(Grok), 로컬 Antigravity 언어 서버 | 켜져 있을 때 10분마다(변경 가능). 항상 프록시 앱의 로컬 포트로 보내며 절대 직접 연결하지 않음(포트가 없으면 조회 안 함) |
| 끊김 진단 | 직접 연결: 119.29.29.29 / 223.5.5.5의 HTTP 조회 API(qq.com 조회), 프록시 경유: `www.gstatic.com/generate_204`, DNS: 시스템 DNS로 www.baidu.com 조회(캐시 없이), 진단 시 라우터에 ping | 켜져 있을 때 직접 연결은 10초마다, 프록시 경유와 DNS는 30초마다 한 번. 실패할 때만 전체 진단 |

국가 / ASN은 프록시 앱에 포함된 오프라인 데이터베이스(`country.mmdb`, `ASN.mmdb`)를 쓰며, 연결 IP를 어디에도 보내지 않습니다.
AI 사용량은 각 도구가 이 PC에 저장한 로그인 정보를 쓰며 그 도구 자체의 서비스로만 보냅니다. 저장, 로그 기록, 갱신은 하지 않습니다.
재생 중인 곡은 Windows 미디어 컨트롤에서 읽으며 네트워크를 쓰지 않습니다.
알림도 네트워크를 쓰지 않습니다. 그날의 알림은 메모리에만 두고 내용은 디스크나 로그에 쓰지 않으며, 기본적으로 아일랜드에도 표시하지 않습니다. 로컬 포트 `127.0.0.1:47900`은 토큰이 있는 AI 훅 호출만 받습니다.
mihomo 컨트롤러 비밀 키는 실행 중에 설정 파일에서 읽을 뿐 저장하거나 외부로 보내지 않습니다.

클립보드 기록은 인터넷에 연결하지 않습니다. 기록은 이 PC(`%LOCALAPPDATA%\MicaBar\clipboard`, 암호화)나 메모리에만 있고 로그에도 쓰지 않습니다.

## 소스에서 빌드

Rust(rustup), Visual Studio C++ Build Tools, Node.js + pnpm이 필요합니다.

```powershell
pnpm install
pnpm build            # exe 하나: src-tauri\target\release\micabar.exe
pnpm release          # 설치 파일 + 포터블 + 업데이트 매니페스트 -> dist\release-<버전>\ (업데이트 서명 키 keys\micabar.key 필요)
```

구조: `src-tauri\src\`(Rust 백엔드: 소켓 테이블, ETW, mihomo 컨트롤러, 출구 확인, 누출 가드, 창 제어, 유리 효과 캡처…),
`ui\`(번들러 없는 순수 HTML / CSS / JS, `ui\i18n\`에 언어별 번역이 있으며 코드 속 중국어 원문이 키), `tools\`(릴리스 스크립트, 테스트 VM 드라이버).

## 면책 조항

MicaBar는 작성자가 개인적으로 개발한 무료 오픈소스 소프트웨어로, "있는 그대로" 제공되며 명시적이든 묵시적이든 어떠한 보증도 하지 않습니다.
이 PC의 네트워크 연결, 프로세스, 시스템 알림, AI 도구의 로그인 상태를 읽지만, 이 데이터는 이 PC에서만 쓰입니다.
"출구 제어"와 "누출 방지"는 프록시 앱의 오버라이드 설정을 바꾸고 방화벽 규칙을 추가하며 프록시 앱을 다시 시작할 수 있습니다.
이 소프트웨어의 사용 또는 사용 불가로 생긴 어떠한 손실(데이터 손실, 네트워크 끊김, 계정 제한 등)에 대해서도 작성자는 책임지지 않습니다.
현지 법령과 각 서비스 약관을 지키며 사용하세요. MicaBar는 Clash, mihomo, Anthropic, OpenAI, Google, xAI 등 언급된 프로젝트나 회사와 관련이 없으며, 이름과 상표는 각 소유자의 것입니다.
